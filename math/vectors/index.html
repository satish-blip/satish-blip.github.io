Vectors and the dot product

Almost every model on this site starts by turning an example into a list of numbers and then taking a dot product with a list of weights. This page builds that one operation from scratch: what it computes, why it measures angle, and why that makes it the workhorse of machine learning.

What is a vector, in plain words?

The idea

Suppose we want to predict the price of a house. The first thing any learning algorithm needs is a way to write the house down. A natural choice is a short list of measurements: living area 2,104 square feet, 3 bedrooms. That list, \(x=(2104,\,3)\), is a vector.

The same list can be read in two ways. As data, it is a row in a spreadsheet. As geometry, it is an arrow from the origin to the point \((2104, 3)\). Switching freely between the two views is the whole trick of linear algebra: algebra tells us how to compute, geometry tells us what the computation means.

How it works

  1. Write each example as a vector of features \(x\in\mathbb R^d\).
  2. Add vectors and multiply them by numbers, component by component.
  3. Compare two vectors with the dot product \(a\cdot b=\sum_j a_jb_j\).
  4. Read the result geometrically: it is large when the arrows point the same way, zero when they are perpendicular.

An everyday picture

Pushing a shopping trolley with a sloped handle. Only the part of your push that points along the aisle moves the trolley forward; the part pressing down is wasted. The dot product measures exactly that useful part: how much of one arrow lies along another.

Good at
  • Scoring: a linear model is one dot product
  • Similarity: cosine similarity for text and images
  • Cheap: \(d\) multiplications and \(d-1\) additions
Watch out for
  • Scale: a long vector gets a big dot product even if the angle is poor
  • Units: features on different scales dominate unless you standardise

1Lists of numbers that are also arrows

Drag the tips of \(a\) (purple) and \(b\) (teal). The dashed arrows show \(a+b\) and \(c\,a\).

Notation

We write a vector with \(d\) components as a column, \(x=\begin{bmatrix}x_1\\ \vdots\\ x_d\end{bmatrix}\in\mathbb R^d\). The subscript \(j\) picks a component; it is not a power. When we have many examples we will index them with a superscript, \(x^{(i)}\), so \(x^{(i)}_j\) is feature \(j\) of example \(i\).

Two operations

Both are done one component at a time:

$$a+b=\begin{bmatrix}a_1+b_1\\ \vdots\\ a_d+b_d\end{bmatrix},\qquad c\,a=\begin{bmatrix}c\,a_1\\ \vdots\\ c\,a_d\end{bmatrix}.$$

Geometrically, \(a+b\) means "walk along \(a\), then along \(b\)": the diagonal of the parallelogram the two arrows make. Multiplying by \(c\) stretches the arrow by \(c\), and flips it when \(c<0\).

Everything else in linear algebra is built from these two moves. A combination \(c_1a+c_2b\) is called a linear combination; the set of all of them is the span of \(a\) and \(b\). In 2-D, two arrows that do not lie on one line span the whole plane.

Going deeper: what makes something a vector space

Mathematicians define vectors by what you can do with them rather than by what they look like. A vector space is any set where addition and scaling behave as you would expect: addition is commutative and associative, there is a zero vector, every vector has a negative, and scaling distributes, \(c(a+b)=ca+cb\) and \((c+k)a=ca+ka\). Lists of numbers satisfy these rules, but so do polynomials, functions and matrices, which is why the same ideas apply to all of them.

Vectors \(v_1,\dots,v_k\) are linearly independent if the only combination giving zero is the trivial one: \(\sum c_iv_i=0\Rightarrow c_i=0\) for all \(i\). A basis is an independent set that spans the space, and every basis of the same space has the same number of vectors: the dimension. In a basis each vector has exactly one list of coordinates, which is what lets us write \(x=(x_1,\dots,x_d)\) in the first place.

2The dot product

How do we measure whether two vectors "agree"? The answer is one formula that has both an algebraic and a geometric reading.

Here is the definition, which is just "multiply matching components and add":

$$a\cdot b \;=\; a^\top b \;=\; \sum_{j=1}^{d}a_j b_j .$$

Written this way, it is not obvious why this number should have anything to do with angles. Let us show that it does. Take the triangle with sides \(a\), \(b\) and \(a-b\), and let \(\theta\) be the angle between \(a\) and \(b\).

  1. \(\|a-b\|^2=\|a\|^2+\|b\|^2-2\|a\|\|b\|\cos\theta\)
    The law of cosines from school geometry, applied to our triangle.
  2. \(\|a-b\|^2=\sum_j(a_j-b_j)^2=\sum_j a_j^2+\sum_j b_j^2-2\sum_j a_jb_j\)
    The same length, computed from components instead (Pythagoras in \(d\) dimensions).
  3. \(\|a\|^2+\|b\|^2-2\,a\cdot b=\|a\|^2+\|b\|^2-2\|a\|\|b\|\cos\theta\)
    Both lines equal \(\|a-b\|^2\), so set them equal; \(\sum_j a_j^2=\|a\|^2\).
  4. \(\boxed{a\cdot b=\|a\|\,\|b\|\cos\theta}\)
    Cancel the common terms and divide by \(-2\).

So the dot product is the product of the two lengths, discounted by how far apart the arrows point. Three cases follow at once:

  • \(\theta<90^\circ\): \(\cos\theta>0\), the dot product is positive (the vectors agree).
  • \(\theta=90^\circ\): it is exactly zero; we call the vectors orthogonal.
  • \(\theta>90^\circ\): it is negative (they disagree).
Algorithm: dot product, length and angle
  1. input vectors \(a, b\) of length \(d\)
  2. s \(\leftarrow 0\); na \(\leftarrow 0\); nb \(\leftarrow 0\)
  3. for \(j = 1\) to \(d\) do
  4. s \(\leftarrow\) s \(+ a_j b_j\) dot product
  5. na \(\leftarrow\) na \(+ a_j^2\); nb \(\leftarrow\) nb \(+ b_j^2\)
  6. \(\|a\| \leftarrow \sqrt{\text{na}}\), \(\|b\| \leftarrow \sqrt{\text{nb}}\)
  7. \(\cos\theta \leftarrow s / (\|a\|\,\|b\|)\) undefined if either vector is 0
  8. return \(s\), \(\theta = \arccos(\cos\theta)\)

There is a second, very useful reading. \(\|b\|\cos\theta\) is the length of the shadow that \(b\) casts on the line through \(a\). So \(a\cdot b=\|a\|\times(\text{shadow of } b \text{ on } a)\). When \(a\) has length 1, the dot product is the shadow. That is the idea behind projections.

Going deeper: Cauchy–Schwarz, and why "angle" makes sense in 100 dimensions

In 2-D or 3-D we can see the angle. In \(\mathbb R^{100}\) we cannot, so we define \(\cos\theta=\frac{a\cdot b}{\|a\|\|b\|}\). For that to be a cosine it must lie in \([-1,1]\). That is the Cauchy–Schwarz inequality:

$$|a\cdot b|\le\|a\|\,\|b\| .$$

Proof. For any real \(t\), \(0\le\|a-tb\|^2=\|a\|^2-2t\,a\cdot b+t^2\|b\|^2\). A quadratic in \(t\) that is never negative has at most one real root, so its discriminant is \(\le0\): \(4(a\cdot b)^2-4\|a\|^2\|b\|^2\le0\). Take square roots. Equality holds exactly when \(a-tb=0\) for some \(t\), that is, when the vectors are parallel. \(\square\)

The dot product is one example of an inner product: any rule \(\langle a,b\rangle\) that is symmetric, linear in each argument and has \(\langle a,a\rangle>0\) for \(a\ne0\). For example \(\langle a,b\rangle_M=a^\top Mb\) with \(M\) symmetric positive definite. The Mahalanobis distance used in GDA is the length from \(M=\Sigma^{-1}\). Cauchy–Schwarz holds for all of them with the same proof.

3Length: norms

Drag the point. The shape drawn through it is every point with the same \(p\)-norm.

The length of a vector came out of the derivation above as \(\|a\|=\sqrt{a\cdot a}\). That is the familiar straight-line length, the L2 norm. It is not the only sensible way to measure size. The general family is

$$\|x\|_p=\Big(\sum_{j}|x_j|^p\Big)^{1/p},\qquad \|x\|_1=\sum_j|x_j|,\quad \|x\|_\infty=\max_j|x_j|.$$

The L1 norm is the "taxi-cab" distance: how far you walk on a grid of streets. The L∞ norm only looks at the largest component. Move the slider and watch the set of points with norm 1 (the unit ball) change from a diamond to a circle to a square.

Why care? The lasso penalises \(\|w\|_1\) and ridge penalises \(\|w\|_2^2\). The diamond has corners on the axes, which is why L1 drives weights exactly to zero. The distance between two points is the norm of their difference, \(\|a-b\|\), which is what k-nearest-neighbours and k-means use.

Going deeper: what counts as a norm

A function \(\|\cdot\|\) is a norm if (1) \(\|x\|\ge0\) with equality only at \(x=0\), (2) \(\|cx\|=|c|\,\|x\|\), and (3) the triangle inequality \(\|a+b\|\le\|a\|+\|b\|\) holds. For \(p\ge1\) the \(p\)-norm satisfies all three. For \(p<1\) the triangle inequality fails: the "unit ball" caves inwards and is no longer convex. That is why \(p=1\) is the smallest \(p\) that still gives a convex penalty, and so the natural convex stand-in for counting non-zero weights.

In finite dimensions all norms are equivalent up to constants, for example \(\|x\|_\infty\le\|x\|_2\le\|x\|_1\le\sqrt d\,\|x\|_2\). The constant \(\sqrt d\) grows with dimension, which is one face of the curse of dimensionality. Hölder's inequality generalises Cauchy–Schwarz: \(|a\cdot b|\le\|a\|_p\|b\|_q\) whenever \(\tfrac1p+\tfrac1q=1\). The pair \((1,\infty)\) is the one behind the lasso's optimality conditions.

4Cosine similarity: angle without length

The dot product mixes two things: how long the vectors are and how well they line up. Often we only care about the second. If we count words in documents, a long article about football will have a larger dot product with everything than a short one, simply because it has more words. Dividing out the lengths removes that effect:

$$\cos\theta=\frac{a\cdot b}{\|a\|\,\|b\|}\in[-1,1].$$

This is cosine similarity. It is 1 when the vectors point the same way, 0 when they share nothing, and \(-1\) when they point in opposite directions. Edit the word counts on the right: doubling every count in a document changes its dot products but leaves its cosines unchanged.

Word vectors, sentence embeddings and dense retrieval all rank results by cosine similarity, or by the dot product of vectors that have been scaled to length 1, which is the same thing.

5Span, independence and a basis

Drag the two basis arrows \(b_1\) (purple) and \(b_2\) (teal), and the point \(x\) (orange). The slanted grid is the coordinate system the new basis gives you; the dashed path shows \(x=c_1b_1+c_2b_2\).

Pages about PCA, eigenvectors and the SVD keep saying things like "use the eigenvectors as a new set of axes" or "change to the eigen-basis". This section says precisely what that means.

Linear combinations and span

Take some vectors \(b_1,b_2\). Scaling them and adding the results, \(c_1b_1+c_2b_2\), gives a linear combination; the numbers \(c_1,c_2\) are its coefficients. The set of every point you can reach this way is the span of \(b_1,b_2\). Two arrows pointing in different directions span the whole plane: walk some amount along \(b_1\), then some amount along \(b_2\), and you can reach any spot. Press Dependent: now both arrows lie on one line, and their span is only that line.

Linear independence

Vectors are linearly independent when none of them is a combination of the others; equivalently, the only way to make \(c_1b_1+c_2b_2=0\) is \(c_1=c_2=0\). Dependent vectors waste a direction: one of them adds nothing new to the span. In a data matrix, dependent columns mean redundant features (area in square feet and in square metres), which is exactly what makes the rank drop and \(X^\top X\) impossible to invert.

Basis, dimension and coordinates

A basis is a set of independent vectors that spans the whole space. Every basis of the plane has exactly 2 vectors, every basis of \(\mathbb R^d\) has \(d\): that number is the dimension. The standard basis \(e_1=(1,0),\ e_2=(0,1)\) is the one we use without thinking: the "coordinates" \((x_1,x_2)\) of a point are its coefficients in that basis.

Any other basis gives the same point different coordinates. If \(x=c_1b_1+c_2b_2\), then \(c=(c_1,c_2)\) are the coordinates of \(x\) in the basis \(b_1,b_2\). Put the basis vectors in the columns of a matrix \(B\) and this is one equation:

  1. \(x=c_1b_1+c_2b_2=Bc\)
    A matrix times a vector is a combination of its columns (see matrices).
  2. \(c=B^{-1}x\)
    Independent columns make \(B\) invertible, so every \(x\) has exactly one set of coordinates. This is a change of basis.
  3. \(c=B^\top x\ \) if the basis is orthonormal
    For perpendicular unit vectors \(B^\top B=I\), so \(B^{-1}=B^\top\): each coordinate is just a dot product, \(c_i=b_i\cdot x\). Try Rotated.

This is what "a new set of axes" means everywhere on this site. PCA computes \(c=V^\top(x-\mu)\), the coordinates of each centred data point in the orthonormal basis of principal components, and keeps only the first few. The eigendecomposition \(A=V\Lambda V^{-1}\) changes to the eigen-basis (\(V^{-1}\)), stretches, and changes back (\(V\)). An embedding of dimension 768 is a set of coordinates in a 768-dimensional space whose basis the network chose for itself.

Going deeper: subspaces, and what a matrix looks like in another basis

A subspace is a set of vectors closed under combinations: any span is one, such as a line or a plane through the origin. The column space and null space on the rank section are subspaces, and rank + nullity = number of columns says their dimensions add up.

If a map has matrix \(A\) in the standard basis, then in the basis \(B\) it has matrix \(B^{-1}AB\): convert coordinates to standard (\(B\)), apply \(A\), convert back (\(B^{-1}\)). Matrices related this way are called similar; they have the same determinant, trace and eigenvalues, because they are the same map in different coordinates. Diagonalising \(A\) means finding a basis in which \(B^{-1}AB\) is diagonal.

Algorithm: coordinates of a vector in a new basis
  1. input basis vectors \(b_1,\dots,b_n\) as the columns of \(B\), a vector \(x\)
  2. if \(B^\top B=I\) then \(c\leftarrow B^\top x\) orthonormal: one dot product per coordinate
  3. else solve \(Bc=x\) for \(c\) elimination; fails if the columns are dependent
  4. check: \(\sum_i c_i b_i\) should equal \(x\)
  5. return \(c\)

6Where the dot product shows up in ML

Once you can see a dot product, you start seeing it everywhere. Each of these is \(a\cdot b\) with a different name for \(a\) and \(b\).

Linear models

A prediction is \(h_\theta(x)=\theta^\top x\): the features weighted and summed. Linear and logistic regression are this one dot product followed by nothing or by a sigmoid.

A neuron

A neuron computes \(g(w^\top x+b)\). Its decision boundary is the set where \(w^\top x+b=0\): all points whose shadow on \(w\) has the same length, which is a line (a hyperplane).

Attention

Attention scores how relevant word \(j\) is to word \(i\) with \(q_i\cdot k_j/\sqrt{d}\). The \(\sqrt d\) keeps the dot product from growing with dimension.

Kernels

An SVM only ever needs dot products between examples. Replacing \(x\cdot z\) with a kernel \(K(x,z)\) is the kernel trick.

Projections and PCA

With a unit vector \(u\), \(u\cdot x\) is the coordinate of \(x\) along \(u\). PCA picks the \(u\) that makes these coordinates vary the most.

Matrix products

Every entry of \(AB\) is a dot product of a row of \(A\) with a column of \(B\). The next page builds on exactly this.

7The same thing in Python (NumPy)

import numpy as np
a, b = np.array([3., 1.]), np.array([1., 2.])
a + b, 1.5 * a                       # component-wise
a @ b                                  # dot product: 3*1 + 1*2 = 5
np.linalg.norm(a), np.linalg.norm(a, 1), np.linalg.norm(a, np.inf)
cos = a @ b / (np.linalg.norm(a) * np.linalg.norm(b))
theta = np.degrees(np.arccos(cos))      # angle between them
shadow = a @ b / np.linalg.norm(a)      # length of b's shadow on a
X = np.random.randn(100, 5); w = np.random.randn(5)
scores = X @ w                          # 100 dot products at once: a linear model
