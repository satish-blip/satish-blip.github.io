Matrices, rank and inverses

A matrix is usually introduced as a table of numbers. It is far more useful to see it as a machine that moves every point in space. Once you see that, the determinant, rank and inverse stop being formulas to memorise and become questions you can answer by looking: how much does it stretch, how much does it flatten, and can it be undone?

What is a matrix, in plain words?

The idea

Go back to the housing example: each house is a vector \(x^{(i)}=(\text{area},\text{bedrooms})\). If we have \(n\) houses, we can stack them as the rows of one table \(X\) with \(n\) rows and 2 columns. That table is a matrix, and it lets us write "compute a prediction for every house" as one operation, \(X\theta\).

There is a second way to read a matrix. Multiplying a vector by a matrix \(A\) produces a new vector, so \(A\) is a function \(x\mapsto Ax\). These functions are special: they keep straight lines straight and keep the origin fixed. They can rotate, stretch, shear, reflect, or flatten space, and nothing else.

How it works

  1. The columns of \(A\) are where the basis arrows \(e_1, e_2, \dots\) land.
  2. Every other point lands at the same combination of those columns: \(Ax=x_1a_1+x_2a_2+\dots\).
  3. The determinant says how much areas (volumes) are scaled; the rank says how many dimensions survive.
  4. If nothing is flattened, the inverse \(A^{-1}\) undoes the move, and that is how we solve \(Ax=b\).

An everyday picture

Drawing on a sheet of rubber pinned at one corner. Stretching or twisting the sheet moves every drawing on it, but straight lines stay straight and the gridlines stay evenly spaced. Press the sheet flat against a ruler and the drawing collapses onto a line: you can no longer recover where anything came from. That collapse is what "rank-deficient" and "not invertible" mean.

Good at
  • Describing a whole dataset or a whole layer in one symbol
  • Composing steps: do \(B\) then \(A\) is just \(AB\)
  • Fast on hardware: GPUs are built for matrix products
Watch out for
  • Order matters: \(AB\ne BA\) in general
  • Nearly flat (ill-conditioned) matrices make inverses unstable

1A matrix moves space

Drag the purple and teal tips: they are the two columns of \(A\), the places where \(e_1=(1,0)\) and \(e_2=(0,1)\) land. Drag the orange tip to move \(x\); the faint arrow is \(x\) before the move.

Why should the columns tell the whole story? Write any \(x\) in terms of the basis arrows, \(x=x_1e_1+x_2e_2\). A matrix respects addition and scaling (that is what "linear" means), so

$$Ax=A(x_1e_1+x_2e_2)=x_1\,Ae_1+x_2\,Ae_2=x_1\,a_1+x_2\,a_2 .$$

And \(Ae_1\) is just the first column of \(A\). So once we know where the two basis arrows go, we know where every point goes: walk \(x_1\) steps along the new first column and \(x_2\) steps along the new second column. The grid on the left is the old square grid after the move; it stays a grid of parallelograms, which is why linear maps are so easy to reason about.

Going deeper: every linear map is a matrix

A function \(L:\mathbb R^n\to\mathbb R^m\) is linear if \(L(\alpha x+\beta y)=\alpha L(x)+\beta L(y)\) for all vectors and numbers. The argument on the left proves that every such \(L\) equals multiplication by the matrix whose \(j\)-th column is \(L(e_j)\). So "linear map" and "matrix" are two names for the same thing, once a basis is fixed. Change the basis and the matrix changes, but the map does not. That idea returns in eigendecomposition, which looks for the basis where the matrix is simplest.

A neural-network layer \(x\mapsto Wx+b\) is affine, not linear, because it moves the origin. A standard trick turns it into a linear map one dimension up: append a 1 to \(x\), and put \(b\) as an extra column of \(W\). It is the same trick as the column of ones in the regression design matrix.

2Matrix multiplication: dot products, and doing one move after another

To multiply \(A\) (\(m\times k\)) by \(B\) (\(k\times n\)), each entry of the product is a dot product:

$$(AB)_{ij}=\sum_{t=1}^{k}A_{it}B_{tj}=(\text{row } i \text{ of } A)\cdot(\text{column } j\text{ of } B).$$

The inner sizes must match (\(k\)), because a dot product needs two lists of the same length. Click any entry of the result to see which row and column produced it.

Algorithm: matrix multiplication \(C = AB\)
  1. input \(A\) of size \(m\times k\), \(B\) of size \(k\times n\) inner sizes must match
  2. for \(i = 1\) to \(m\) do
  3. for \(j = 1\) to \(n\) do
  4. \(C_{ij} \leftarrow 0\)
  5. for \(t = 1\) to \(k\) do \(C_{ij} \leftarrow C_{ij} + A_{it}B_{tj}\) row i · column j
  6. return \(C\) m·n·k multiplications

Why this odd rule? Because it is exactly what makes \((AB)x=A(Bx)\). Applying \(B\) and then \(A\) is the same as applying the single matrix \(AB\). Reading right to left, \(AB\) means "first \(B\), then \(A\)". Since rotating then shearing differs from shearing then rotating, \(AB\) and \(BA\) are usually different.

Two special cases are worth naming. The identity \(I\) has ones on the diagonal and leaves every vector alone, so \(AI=IA=A\). The transpose \(A^\top\) swaps rows and columns, and a dot product is a tiny matrix product: \(a\cdot b=a^\top b\).

Going deeper: four ways to read a product, and the rules that follow

The same product \(C=AB\) can be read four ways, and each is useful:

  • Entries: \(C_{ij}\) = row \(i\) of \(A\) · column \(j\) of \(B\).
  • Columns: column \(j\) of \(C\) is \(A\) times column \(j\) of \(B\), a combination of the columns of \(A\).
  • Rows: row \(i\) of \(C\) is row \(i\) of \(A\) times \(B\), a combination of the rows of \(B\).
  • Outer products: \(AB=\sum_{t=1}^{k}a_{:t}\,b_{t:}\), a sum of \(k\) rank-one matrices. This is the view behind the SVD.

From "product = composition" come the rules: \((AB)C=A(BC)\), because composing functions is associative. Also \((AB)^\top=B^\top A^\top\) and \((AB)^{-1}=B^{-1}A^{-1}\): to undo "put on socks, then shoes", take off the shoes first. Computing \(AB\) naively takes \(mkn\) multiplications. That is why the order of a chain matters: \((AB)v\) costs far more than \(A(Bv)\) when \(v\) is a vector.

3The determinant: how much area is scaled

The unit square (area 1) lands on the shaded parallelogram. Drag the tips of \(a_1\) and \(a_2\), or slide \(t\) to push \(a_2\) onto the line of \(a_1\).

The unit square, spanned by \(e_1\) and \(e_2\), lands on the parallelogram spanned by the columns \(a_1=(a,c)\) and \(a_2=(b,d)\). Its signed area is the determinant:

$$\det\begin{bmatrix}a&b\\ c&d\end{bmatrix}=ad-bc .$$

Where does \(ad-bc\) come from? Put the parallelogram inside the rectangle of width \(a+b\) and height \(c+d\). The rectangle has area \((a+b)(c+d)\). Around the parallelogram are two triangles of area \(\tfrac12ac\), two of area \(\tfrac12bd\) and two small rectangles of area \(bc\). Subtracting them leaves \((a+b)(c+d)-ac-bd-2bc=ad-bc\).

Every shape is made of tiny squares, and every tiny square is scaled by the same factor, so all areas are multiplied by \(|\det A|\). A negative sign means the move also flips space over (like a mirror). And if \(\det A=0\), the parallelogram has no area: the whole plane has been flattened onto a line or a point.

Going deeper: properties of the determinant

Because \(\det\) is "the area scale factor", these follow almost without calculation:

  • \(\det(AB)=\det A\,\det B\): scaling by one factor and then another multiplies them.
  • \(\det(A^{-1})=1/\det A\), and \(\det I=1\).
  • \(\det A^\top=\det A\).
  • \(\det A=\prod_i\lambda_i\), the product of the eigenvalues (each eigen-direction is stretched by \(\lambda_i\)).
  • Swapping two rows flips the sign; adding a multiple of one row to another leaves it unchanged. This is why elimination computes determinants: reduce to a triangular matrix and multiply the diagonal.

The general formula (Leibniz) is \(\det A=\sum_{\sigma}\operatorname{sgn}(\sigma)\prod_i A_{i,\sigma(i)}\), a sum over all \(n!\) permutations. It is never used for computing, but it shows \(\det\) is a polynomial in the entries. The Gaussian density uses \(\det\Sigma\) to normalise the volume of its ellipsoid.

4Rank: how many dimensions survive

The determinant says whether space is flattened. The rank says how badly. It is the number of independent directions the columns point in, which is the dimension of the set of all outputs \(\{Ax\}\) (the column space).

A \(3\times3\) matrix of rank 3 keeps 3-D space 3-D. Rank 2 squashes it onto a plane; rank 1 onto a line. When a column is a combination of the others, it adds no new direction. For example, if column 3 = column 1 + column 2, the rank is at most 2.

How do we compute it? By row reduction (Gaussian elimination). Adding a multiple of one row to another, swapping rows, or scaling a row never changes which combinations of the columns are zero, so it never changes the rank. We use these moves to clear everything below and above each leading entry (a pivot). The rank is the number of pivots.

Algorithm: row reduction (Gauss–Jordan) and rank
  1. input \(A\) (\(m\times n\)), tolerance \(\varepsilon\)
  2. \(r \leftarrow 1\) next pivot row
  3. for each column \(c = 1\) to \(n\) while \(r \le m\) do
  4. \(p \leftarrow\) row \(\ge r\) with the largest \(|A_{pc}|\) partial pivoting
  5. if \(|A_{pc}| < \varepsilon\) then continue no pivot in this column
  6. swap rows \(p\) and \(r\); divide row \(r\) by \(A_{rc}\)
  7. for every other row \(i\) do row\(_i \leftarrow\) row\(_i - A_{ic}\,\)row\(_r\)
  8. \(r \leftarrow r + 1\)
  9. return reduced matrix, rank \(= r - 1\) (number of pivots)
$$\underbrace{\operatorname{rank}(A)}_{\text{dimensions kept}}+\underbrace{\dim\operatorname{null}(A)}_{\text{dimensions crushed to }0}=n\ (\text{number of columns}).$$

This is the rank–nullity theorem. The null space is the set of \(x\) with \(Ax=0\): the directions that get flattened. Edit the matrix or pick a preset, then step through the elimination.

Going deeper: row rank equals column rank, and other rank facts

Row operations replace rows by combinations of rows, so they do not change the row space. They also do not change which combinations of columns are zero, because \(Ax=0\iff EAx=0\) for any invertible \(E\). In the reduced form both counts are visibly the number of pivots. So the number of independent rows always equals the number of independent columns, a surprising fact that is not obvious from the definition.

Useful consequences:

  • \(\operatorname{rank}(AB)\le\min(\operatorname{rank}A,\operatorname{rank}B)\): composing can only lose dimensions.
  • \(\operatorname{rank}(A^\top A)=\operatorname{rank}A\). Proof: if \(A^\top Ax=0\) then \(x^\top A^\top Ax=\|Ax\|^2=0\), so \(Ax=0\). The two null spaces are equal, and rank–nullity does the rest. This is exactly why the normal equations are solvable when the features are independent.
  • A rank-\(r\) \(m\times n\) matrix can be written as a product of \(m\times r\) and \(r\times n\) matrices: \(r(m+n)\) numbers instead of \(mn\).

5The inverse, and solving \(Ax=b\)

Drag \(b\). The coloured path shows \(x_1a_1\) followed by \(x_2a_2\): the recipe that reaches \(b\).

Many problems ask the reverse question: we know where we want to land, \(b\), so which \(x\) gets us there? In other words, solve \(Ax=b\). Geometrically: how many steps along \(a_1\) and along \(a_2\) reach \(b\)?

If \(A\) does not flatten space (\(\det A\ne0\), full rank), every \(b\) is reached by exactly one \(x\), and the map \(b\mapsto x\) is itself a matrix, the inverse \(A^{-1}\), with \(A^{-1}A=AA^{-1}=I\). For a \(2\times2\) matrix:

$$A^{-1}=\frac{1}{ad-bc}\begin{bmatrix}d&-b\\ -c&a\end{bmatrix},\qquad x=A^{-1}b .$$

You can check it by multiplying out \(A^{-1}A\). Notice the \(\frac{1}{ad-bc}\): as the determinant goes to zero the inverse blows up, which is the algebra's way of saying the flattening cannot be undone. When \(\det A=0\), \(b\) is reachable only if it lies on the squashed line, and then infinitely many \(x\) work (add anything from the null space).

Algorithm: solve \(Ax=b\) for a \(2\times 2\) matrix
  1. \(D \leftarrow ad - bc\)
  2. if \(|D| < \varepsilon\) then
  3. if \(b\) lies on the column line then return "infinitely many" else return "no solution"
  4. \(x_1 \leftarrow (d\,b_1 - b\,b_2)/D\), \(x_2 \leftarrow (-c\,b_1 + a\,b_2)/D\) x = A⁻¹b, written out
  5. return \(x\)

In practice we almost never form \(A^{-1}\). Solvers (np.linalg.solve) use row reduction or a factorisation directly, which is faster and more accurate. How sensitive the answer is to small changes in \(b\) is measured by the condition number.

Going deeper: the invertible matrix theorem, and conditioning

For a square \(n\times n\) matrix, all of these say the same thing: \(A\) is invertible; \(\det A\ne0\); \(\operatorname{rank}A=n\); the columns are independent; the columns span \(\mathbb R^n\); \(Ax=0\) only for \(x=0\); \(Ax=b\) has exactly one solution for every \(b\); 0 is not an eigenvalue; all singular values are positive.

Invertible is a yes/no question, but computers need a "how close to singular". If \(b\) carries a small error \(\delta b\), the solution moves by \(\delta x=A^{-1}\delta b\), and

$$\frac{\|\delta x\|}{\|x\|}\le\kappa(A)\,\frac{\|\delta b\|}{\|b\|},\qquad\kappa(A)=\|A\|\,\|A^{-1}\|=\frac{\sigma_{\max}}{\sigma_{\min}} .$$

With \(\kappa=10^{8}\), relative errors can grow a hundred-million-fold, and you lose about 8 of the 16 digits a double holds. Forming \(X^\top X\) squares the condition number, which is why lstsq uses QR or the SVD instead.

6A field guide to special matrices

Pick a type and watch what it does to the unit square (shaded) and the unit circle (outline). Drag the grey tip to move \(x\); the orange arrow \(Ax\) shows where it lands.

Most matrices you meet in machine learning are not arbitrary tables. They have a shape, a simple rule about their entries, and each rule shows up as something you can see: a move that only stretches, a move that never changes lengths, a move that can be undone one row at a time. Learning to recognise these shapes is like learning the common chess openings: the rest of linear algebra becomes much easier to read.

The identity matrix \(I\)

Ones on the diagonal, zeros everywhere else. It sends every vector to itself, \(Ix=x\), so it plays the role of the number 1: \(AI=IA=A\). We meet it whenever something must "cancel out": the inverse is defined by \(AA^{-1}=I\), and ridge regression adds \(\lambda I\) to \(X^\top X\) to make it safely invertible.

Diagonal matrices: stretch each axis on its own

Only the diagonal entries \(d_1,d_2,\dots\) can be non-zero. Then \(Dx=(d_1x_1,d_2x_2,\dots)\): each coordinate is scaled separately and nothing is mixed. Everything is easy: \(D^k\) raises each \(d_i\) to the \(k\)-th power, \(D^{-1}\) has \(1/d_i\), and \(\det D=d_1d_2\cdots\). The trace \(\operatorname{tr}A\) is the sum of the diagonal entries of any square matrix; for a diagonal matrix it is the sum of the stretches. The whole point of the eigendecomposition and the SVD is to find axes in which a matrix becomes diagonal.

Triangular matrices: solve one row at a time

A lower-triangular matrix has zeros above the diagonal; an upper-triangular one has zeros below. In \(Lx=b\) the first row involves only \(x_1\), the second only \(x_1,x_2\), and so on, so you solve from the top down (forward substitution), with no elimination needed. The determinant is just the product of the diagonal. That is why LU, QR and Cholesky all turn a hard matrix into triangular pieces.

Transpose and symmetric matrices

The transpose \(A^\top\) swaps rows and columns: \((A^\top)_{ij}=A_{ji}\). A matrix is symmetric when \(A=A^\top\), a mirror image of itself across the diagonal. Symmetric matrices arise whenever entry \((i,j)\) measures something mutual between \(i\) and \(j\): the covariance of features \(i\) and \(j\), the similarity \(k(x_i,x_j)\) in a kernel matrix, the second derivative \(\partial^2 f/\partial\theta_i\partial\theta_j\) in a Hessian, or \(X^\top X\) in least squares.

What do they look like as moves? Choose Symmetric: the circle becomes an ellipse, and the two dashed eigen-directions are always perpendicular. A symmetric matrix just stretches along two perpendicular axes, with no twist. That fact, the spectral theorem, is why PCA gets perpendicular principal components.

Orthogonal matrices: rotations and reflections

Here is the sentence that is easy to skim past: "an orthogonal matrix is a pure rotation or reflection that keeps lengths." Let us unpack it. A square matrix \(Q\) is orthogonal when its columns are unit-length and perpendicular to each other. Taking dot products of the columns is exactly what \(Q^\top Q\) computes (entry \((i,j)\) is column \(i\) · column \(j\)), so the rule is

$$Q^\top Q=I,\qquad\text{so}\qquad Q^{-1}=Q^\top .$$

Now watch what that does to a length. The squared length of \(Qx\) is a dot product with itself:

  1. \(\|Qx\|^2=(Qx)^\top(Qx)\)
    A squared length is a vector dotted with itself.
  2. \(=x^\top Q^\top Q\,x\)
    The transpose of a product reverses the order: \((Qx)^\top=x^\top Q^\top\).
  3. \(=x^\top x=\|x\|^2\)
    \(Q^\top Q=I\) cancels out.

So every length is unchanged, and the same argument shows every dot product, and hence every angle, is unchanged. A move of the plane that keeps all lengths and angles and fixes the origin can only turn the plane (a rotation, \(\det Q=+1\)) or flip it over a line (a reflection, \(\det Q=-1\)). Choose Rotation or Reflection and drag \(x\): the readout \(\|Ax\|/\|x\|\) stays exactly 1, and the unit square stays a unit square, only turned.

Where you meet them: the eigenvectors of a symmetric matrix form an orthogonal matrix (PCA rotates the data onto them); the \(U\) and \(V\) of the SVD are orthogonal, which is why the SVD reads "rotate, stretch, rotate"; \(Q\) in QR; orthogonal initialisation of RNN weights, which keeps signals from shrinking or exploding; and rotary position embeddings in transformers.

Positive definite: a matrix that "points forward"

A symmetric matrix is positive definite if \(x^\top Ax>0\) for every \(x\ne0\), and positive semi-definite if \(x^\top Ax\ge0\). Since \(x^\top Ax=x\cdot(Ax)\), the condition says that \(Ax\) never points more than \(90^\circ\) away from \(x\): the matrix may stretch and turn, but never pushes a vector backwards. Equivalently, all its eigenvalues are positive, and the function \(f(x)=x^\top Ax\) is a bowl with a single lowest point. Choose Symmetric and push the slider to the ends: once \(|b|\) passes about 1.2 an eigenvalue turns negative, \(x^\top Ax\) can go below zero, and the bowl becomes a saddle.

Covariance matrices are always semi-definite (a variance cannot be negative), the Hessian at a minimum is semi-definite, and kernel matrices must be, which is the condition for a valid kernel. To see \(x^\top Ax\) as a coloured surface (bowl, valley or saddle), the spectral theorem played step by step, and why every covariance matrix is PSD, open the positive semi-definite lab.

Going deeper: why symmetric means perpendicular eigenvectors

Let \(Av=\lambda v\) and \(Aw=\mu w\) with \(\lambda\ne\mu\) and \(A=A^\top\). Then \(\lambda\,(v\cdot w)=(Av)\cdot w=v\cdot(A^\top w)=v\cdot(Aw)=\mu\,(v\cdot w)\). Since \(\lambda\ne\mu\), we must have \(v\cdot w=0\). Collecting the unit eigenvectors as the columns of an orthogonal \(Q\) gives the spectral theorem: \(A=Q\Lambda Q^\top\). Read right to left: rotate into the eigen-axes, stretch, rotate back.

With that, positive definiteness is easy to test: write \(x=Qc\), so \(x^\top Ax=c^\top\Lambda c=\sum_i\lambda_ic_i^2\). This is positive for every \(c\ne0\) exactly when every \(\lambda_i>0\). In practice we test it by attempting a Cholesky factorisation, which succeeds exactly for positive definite matrices.

Not every matrix is one of these types, but every matrix is a product of them. The SVD says any \(A=U\Sigma V^\top\): orthogonal, diagonal, orthogonal. QR says \(A=QR\): orthogonal times triangular.

Algorithm: recognising a special matrix
  1. input square matrix \(A\) (\(n\times n\)), tolerance \(\varepsilon\)
  2. if \(|A_{ij}|<\varepsilon\) for every \(i\ne j\) then diagonal identity if every \(A_{ii}=1\)
  3. else if \(|A_{ij}|<\varepsilon\) for every \(j>i\) (or every \(j<i\)) then triangular
  4. if \(|A_{ij}-A_{ji}|<\varepsilon\) for every pair then symmetric
  5. if \(A^\top A\approx I\) then orthogonal: rotation if \(\det A=+1\), reflection if \(-1\)
  6. if symmetric, try Cholesky \(A=LL^\top\): success \(\Leftrightarrow\) positive definite
  7. return the list of properties found

7Where this shows up in ML

The normal equations

Least squares solves \(X^\top X\theta=X^\top y\). If two features are copies of each other (say area in feet and in metres), \(X\) loses rank, \(X^\top X\) is not invertible, and infinitely many \(\theta\) fit equally well. Ridge adds \(\lambda I\) to make it invertible again.

Layers of a network

Each layer of a neural network is \(g(Wx+b)\): a matrix moves space, then a non-linearity bends it. Without the bend, stacked layers would collapse into one matrix product.

Inverse covariance

Gaussian discriminant analysis uses \(\Sigma^{-1}\) to measure distance in units of spread. A singular covariance (more features than examples) breaks it, which is why LDA shares or shrinks \(\Sigma\).

Low rank on purpose

LoRA fine-tunes a large model by learning a rank-\(r\) update \(BA\) with \(r\) tiny, so only a few parameters change. See the LLM adaptation map and, for the best low-rank approximation, the SVD page.

Batches

A forward pass over a mini-batch is one product \(XW\): every example times every weight column at once, which is why GPUs make training fast.

Attention

All the query–key scores in self-attention are one matrix product \(QK^\top\). Its \(n\times n\) size is the famous quadratic cost.

8The same thing in Python (NumPy)

import numpy as np
A = np.array([[2., 1.], [1., 3.]])
A @ np.array([1., 0.])                 # first column: where e1 lands
np.linalg.det(A)                       # 2*3 - 1*1 = 5: areas scale by 5
np.linalg.matrix_rank(np.array([[1,2,3],[4,5,6],[5,7,9]]))   # 2: row 3 = row 1 + row 2
b = np.array([3., 5.])
x = np.linalg.solve(A, b)              # preferred over np.linalg.inv(A) @ b
np.allclose(A @ x, b)                  # True
np.linalg.cond(A)                      # condition number: how much errors can grow
from scipy.linalg import null_space
null_space(np.array([[1., 2.], [2., 4.]]))   # direction crushed to zero
