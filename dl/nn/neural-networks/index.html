Neural networks, and how they solve XOR

A neuron draws one line. XOR needs two. A hidden layer gives the network several lines at once, and then the next layer combines them. That small idea, stacked many times, is all of deep learning. Build it by hand, watch the hidden layer bend space, then train networks live with backpropagation.

What is a neural network, in plain words?

The problem

Take the simplest puzzle that breaks linear models: two inputs that are each 0 or 1, and the answer is 1 when exactly one of them is 1 (XOR). Plot the four cases and the two "1" corners sit diagonally opposite each other. Logistic regression, LDA and a linear SVM all draw one straight line, and no straight line can put both "1" corners on the same side. We need a model that can build its own curved boundaries, and learn how from the data.

The idea

A neuron takes a few numbers, multiplies each by a weight, adds them up with a bias, and passes the total through a simple bend, the activation function. On its own that is just logistic regression: one straight boundary.

A neural network stacks layers of such neurons. Each hidden layer turns the data into new features, and the bends let the network fold and stretch space until the classes become separable. That is how it solves XOR, which no single straight line can. All the weights are learned together: backpropagation computes how each one should change, and gradient descent makes the change.

How it works

  1. Forward pass: feed the input through every layer to get a prediction.
  2. Measure the error with a loss function (here cross-entropy).
  3. Backward pass: use the chain rule to get the gradient for every weight.
  4. Update all weights a little against their gradients (an optimiser such as Adam), and repeat.

An everyday picture

A team of clerks in a row of offices: the first office sorts letters by simple rules, the next combines those piles into broader categories, and the last makes the final decision. Training is the manager telling each office how to adjust its rules after every mistake.

Good at
  • Learns its own features from raw data
  • Can approximate almost any function given enough neurons
  • Scales to images, text and audio
Watch out for
  • Needs more data and tuning than classical models
  • Non-convex: results depend on initialisation
  • Hard to interpret

1One neuron = one line

A neuron computes \(a=\sigma(w_1x_1+w_2x_2+b)\). The boundary \(w_1x_1+w_2x_2+b=0\) is a straight line, so a single neuron is exactly logistic regression.

Target truth table

2XOR by hand: two lines, then an AND

XOR is true when exactly one input is 1. Notice that

$$x_1\oplus x_2=(x_1\lor x_2)\land\lnot(x_1\land x_2)=\mathrm{AND}\big(\mathrm{OR}(x_1,x_2),\ \mathrm{NAND}(x_1,x_2)\big)$$

Each of OR, NAND and AND is a single neuron (section 1). So a network with two hidden neurons (OR and NAND) and one output neuron (AND of the two) computes XOR exactly:

$$h_1=\sigma(20x_1+20x_2-10),\quad h_2=\sigma(-20x_1-20x_2+30),\quad y=\sigma(20h_1+20h_2-30)$$

Purple edges are positive weights, orange negative; thickness is magnitude. Hover or tap the table rows to light up the network for that input.

3The hidden layer bends space

Slide from the input space \((x_1,x_2)\) to the hidden space \((h_1,h_2)\). In input space the XOR points sit on opposite corners and no line separates them. After the hidden layer, both "true" points land in the same spot, and one straight line (the output neuron) finishes the job.

This is the central intuition of deep learning: each layer re-represents the data so that the next layer's job is easier. The last layer of a classifier is always just a linear model (logistic regression) on the features the earlier layers learned.

The warped grid shows what the hidden layer does to the whole plane, not only to the four points: the sigmoid squashes everything into the unit square and folds the two "true" corners together.

Why not just more linear layers? Without the non-linearity, \(W_2(W_1x+b_1)+b_2=(W_2W_1)x+(W_2b_1+b_2)\) is still one linear map, still one line. The bend comes entirely from \(\sigma\). See the activations page.
Same idea as kernels. The SVM on the SVM page also lifts XOR into a space where it is linearly separable, but with a fixed feature map. A neural network learns its feature map from data.

5Forward pass and backpropagation

Training a network uses the same recipe as logistic regression: define the prediction, define the loss, then follow the gradient downhill. The only new problem is step three: with thousands of weights in several layers, how do we get every partial derivative efficiently? Backpropagation is the answer, and it is nothing more than the chain rule applied in a sensible order.

Step 1: the forward pass

Write \(a^{(0)}=x\) for the input. Each layer takes the previous layer's outputs, forms weighted sums \(z\) (one per neuron, so a matrix–vector product), and bends them with the activation \(\phi\):

$$a^{(0)}=x,\qquad z^{(l)}=W^{(l)}a^{(l-1)}+b^{(l)},\qquad a^{(l)}=\phi\big(z^{(l)}\big),\qquad \hat p=\sigma\big(z^{(L)}\big)$$

Read it as a pipeline: \(W^{(l)}\) has one row per neuron in layer \(l\), and row \(j\) holds the weights neuron \(j\) gives to each input. The last layer is a single logistic-regression neuron on top of learned features.

Step 2: the loss

Loss for binary classification is the same cross-entropy as logistic regression: \(\mathcal L=-\tfrac1n\sum_i\big[y_i\log\hat p_i+(1-y_i)\log(1-\hat p_i)\big]\).

Universal approximation

How powerful is this family? With one hidden layer and enough neurons, a network with a non-polynomial activation can approximate any continuous function on a bounded region as closely as you like. Depth does not add expressive power in principle, but it often needs exponentially fewer neurons than width alone (each layer composes and reuses the previous layer's features).

Going deeper: why weights must start random, and at what scale

If every weight in a layer starts equal, every neuron in that layer computes the same thing, receives the same \(\delta\), and gets the same update: they stay clones forever. Random initialisation breaks this symmetry. The scale matters too. With \(n\) inputs of variance 1 and weights of variance \(v\), \(z\) has variance \(nv\). To keep signals from exploding or dying layer after layer we want \(nv\approx1\): Xavier/Glorot initialisation uses \(v=1/n_{\text{in}}\) (or \(2/(n_{\text{in}}+n_{\text{out}})\)) for tanh; He initialisation uses \(v=2/n_{\text{in}}\) for ReLU, because ReLU zeroes half of its inputs and so halves the variance.

Step 3: backpropagation = the chain rule, organised

Define \(\delta^{(l)}=\partial\mathcal L/\partial z^{(l)}\): "how much would the loss change if this neuron's weighted sum moved a little?". At the output it is simply the error. Each earlier layer's \(\delta\) is obtained from the next layer's by sending it back through the same weights, then scaling by the slope of the activation:

$$\delta^{(L)}=\hat p-y,\qquad \delta^{(l)}=\big(W^{(l+1)\top}\delta^{(l+1)}\big)\odot\phi'\big(z^{(l)}\big)$$
$$\frac{\partial\mathcal L}{\partial W^{(l)}}=\delta^{(l)}a^{(l-1)\top},\qquad \frac{\partial\mathcal L}{\partial b^{(l)}}=\delta^{(l)}$$

One backward sweep reuses each layer's \(\delta\) for the layer below, so all gradients cost about the same as one forward pass. Then any optimiser updates the weights. With regularisation the loss gains \(\lambda_2\lVert W\rVert_2^2/2+\lambda_1\lVert W\rVert_1\), adding \(\lambda_2W+\lambda_1\operatorname{sign}(W)\) to each weight gradient (see L1 and L2).

Algorithm: training a network with backpropagation
  1. input data \((x_i,y_i)\), layer sizes, activation \(\phi\), learning rate \(\eta\)
  2. initialise every \(W^{(l)}\) with small random numbers, \(b^{(l)}\leftarrow0\) random, or all neurons stay identical
  3. repeat for each mini-batch
  4. forward: \(a^{(0)}\leftarrow x\); for \(l=1..L\): \(z^{(l)}\leftarrow W^{(l)}a^{(l-1)}+b^{(l)}\), \(a^{(l)}\leftarrow\phi(z^{(l)})\) store every z and a
  5. \(\mathcal L\leftarrow\) cross-entropy of \(\hat p=\sigma(z^{(L)})\) against \(y\)
  6. backward: \(\delta^{(L)}\leftarrow\hat p-y\)
  7. for \(l=L\) down to 1 do
  8. \(\nabla W^{(l)}\leftarrow\delta^{(l)}a^{(l-1)\top}\); \(\nabla b^{(l)}\leftarrow\delta^{(l)}\)
  9. if \(l>1\): \(\delta^{(l-1)}\leftarrow(W^{(l)\top}\delta^{(l)})\odot\phi'(z^{(l-1)})\) send the error one layer back
  10. update: \(W\leftarrow W-\eta\nabla W\), \(b\leftarrow b-\eta\nabla b\) for every layer or Adam
  11. until the loss stops improving
Going deeper: deriving the backprop equations

Output layer. With \(\hat p=\sigma(z^{(L)})\) and cross-entropy, exactly the same algebra as on the logistic regression page gives \(\partial\mathcal L/\partial z^{(L)}=\hat p-y\).

One layer back. \(z^{(l)}\) affects the loss only through \(a^{(l)}\), which feeds every neuron \(k\) of the next layer via \(z^{(l+1)}_k=\sum_jW^{(l+1)}_{kj}a^{(l)}_j+b_k\). The multivariable chain rule sums over all those paths: \(\delta^{(l)}_j=\sum_k\frac{\partial\mathcal L}{\partial z^{(l+1)}_k}\frac{\partial z^{(l+1)}_k}{\partial a^{(l)}_j}\frac{\partial a^{(l)}_j}{\partial z^{(l)}_j}=\big(\sum_kW^{(l+1)}_{kj}\delta^{(l+1)}_k\big)\phi'(z^{(l)}_j)\). In matrix form that is \((W^{(l+1)\top}\delta^{(l+1)})\odot\phi'(z^{(l)})\).

Weights. \(W^{(l)}_{jk}\) appears only in \(z^{(l)}_j\), with coefficient \(a^{(l-1)}_k\), so \(\partial\mathcal L/\partial W^{(l)}_{jk}=\delta^{(l)}_ja^{(l-1)}_k\): an outer product. "Error at the output end times activity at the input end", the same shape as the LMS rule.

Why it is cheap. Computing each weight's derivative separately would repeat the work for every path through the network. Backprop is reverse-mode automatic differentiation: one backward sweep, cost about two forward passes, which is exactly what loss.backward() does in PyTorch.

Notice \(\phi'\) in every \(\delta\). If \(\phi'\) is small (saturated sigmoid) the signal shrinks layer after layer: the vanishing gradient problem that ReLU, residual connections and normalisation were invented to fix.

6The same thing in Python (PyTorch)

import torch, torch.nn as nn
X = torch.tensor([[0.,0.],[0.,1.],[1.,0.],[1.,1.]]); y = torch.tensor([[0.],[1.],[1.],[0.]])
model = nn.Sequential(nn.Linear(2, 4), nn.Tanh(), nn.Linear(4, 1))
opt = torch.optim.Adam(model.parameters(), lr=0.03, weight_decay=0)   # weight_decay = L2
loss_fn = nn.BCEWithLogitsLoss()
for step in range(2000):
    opt.zero_grad()
    loss = loss_fn(model(X), y)
    loss.backward()           # backpropagation
    opt.step()
torch.sigmoid(model(X)).round()   # tensor([[0.],[1.],[1.],[0.]])
