Activation functions: the non-linearity

Without an activation function, a 100-layer network is just one matrix: a straight line. The activation is what lets networks bend. But its shape also decides how well gradients survive the trip back through many layers. Compare them, train with each one, and watch gradients vanish.

What is an activation function, in plain words?

The problem

On the neural networks page, a hidden layer solved XOR by bending space. But what does the bending? Matrix multiplications only rotate, stretch and shift; stack a hundred of them and you still have one matrix. Something between the layers has to be curved, and the choice of that curve turns out to decide whether a deep network learns quickly, slowly, or not at all.

The idea

After each neuron adds up its weighted inputs, it applies a fixed function to the total. That function is the activation. It must bend: if it were a straight line, a hundred layers would collapse into one linear model and could never solve XOR.

The shape matters for learning too. During backpropagation every layer multiplies the gradient by the activation’s slope. Flat regions (saturation) kill the signal, causing vanishing gradients; ReLU keeps slope 1 for positive inputs but can leave neurons dead.

How it works

  1. Each neuron computes \(z = w^\top x + b\).
  2. It outputs \(a = \phi(z)\) for the chosen activation \(\phi\).
  3. The backward pass multiplies the incoming gradient by \(\phi'(z)\).
  4. Pick \(\phi\) so the network can bend and gradients survive.

An everyday picture

A dimmer switch versus an on/off switch versus a one-way valve: sigmoid and tanh dim smoothly but saturate at the ends, the step function is all-or-nothing (no slope to learn from), ReLU lets current flow one way only.

Good at
  • ReLU / GELU: fast and the default for deep nets
  • tanh: zero-centred, used in RNNs
  • Sigmoid: probabilities and gates
Watch out for
  • Sigmoid in deep stacks: vanishing gradients
  • ReLU with a high learning rate: dead neurons

3Vanishing gradients through depth

The gradient reaching layer \(l\) is a product of one factor per layer above it:

$$\frac{\partial\mathcal L}{\partial a^{(l)}}=\frac{\partial\mathcal L}{\partial a^{(L)}}\prod_{k=l+1}^{L}W^{(k)\top}\operatorname{diag}\big(\phi'(z^{(k)})\big)$$

Sigmoid's slope is at most \(\tfrac14\), so twenty layers can shrink the signal by \(4^{-20}\approx10^{-12}\): the early layers simply stop learning. tanh is better (slope up to 1 at 0) and ReLU passes gradients through unchanged wherever it is active. The chart shows the gradient norm \(\lVert\partial\mathcal L/\partial W^{(l)}\rVert\) in every layer of freshly initialised networks on the moons data (log scale).

Here is exactly how the chart is computed: run the network forward once, then walk backwards multiplying by one factor per layer, and record how big the signal is when it arrives.

Algorithm: measuring gradient flow through depth
  1. input network with \(L\) layers, activation \(\phi\), a batch \(x\)
  2. forward: for \(l=1..L\): \(z^{(l)}\leftarrow W^{(l)}a^{(l-1)}+b^{(l)}\); \(a^{(l)}\leftarrow\phi(z^{(l)})\)
  3. \(g\leftarrow\partial\mathcal L/\partial a^{(L)}\) the error signal at the top
  4. for \(l=L\) down to 1 do
  5. \(g\leftarrow g\odot\phi'(z^{(l)})\) shrinks wherever the slope is below 1
  6. record \(\lVert g\,a^{(l-1)\top}\rVert\) gradient size for layer l's weights
  7. \(g\leftarrow W^{(l)\top}g\) pass the signal one layer down
  8. return the recorded norms, one per layer
Going deeper: why sigmoid shrinks gradients and ReLU does not

\(\sigma'(z)=\sigma(z)(1-\sigma(z))\) is a product of two numbers that add to 1, so it is at most \(\tfrac12\cdot\tfrac12=\tfrac14\), reached only at \(z=0\); away from 0 it is far smaller. \(\tanh'(z)=1-\tanh^2(z)\le1\). ReLU's slope is exactly 1 for every active unit and 0 otherwise. The backward signal is multiplied by \(W^{(k)\top}\operatorname{diag}(\phi'(z^{(k)}))\) at every layer, so its size behaves roughly like a product of \(L\) random factors. If the typical factor is \(c\), the signal scales like \(c^{L}\): any \(c<1\) vanishes exponentially and any \(c>1\) explodes. Good initialisation chooses the weight scale so that \(c\approx1\) for the chosen activation (Xavier: \(\operatorname{Var}W=1/n\) for tanh; He: \(2/n\) for ReLU, compensating for the half of units that are off). That is also why the "edge of chaos" is a narrow target, and why residual connections, which add an identity path with factor exactly 1, made very deep networks easy.

Fixes, in historical order: better activations (ReLU, 2011), careful initialisation (Xavier for tanh, He for ReLU, both used here), normalisation (2015) and residual connections (2015).

4Dead ReLUs

A ReLU neuron whose input is negative for every training point outputs 0 everywhere and has zero gradient everywhere. Nothing can revive it: it is dead. A large learning rate makes this much more likely, because one big update can push the bias far negative.

Leaky ReLU keeps a small slope (0.1 here) for negative inputs, so its neurons never fully die. ELU, GELU and Swish also have non-zero slope there.
