ViLBERT: two streams that talk through co-attention

VisualBERT poured words and image regions into one BERT. ViLBERT, published the same month (Lu et al., 2019), keeps them apart: one transformer for the text, another for the image, and special co-attentional transformer layers (Co-TRM) where the text stream asks the image questions and the image stream asks the text. This page builds that layer from the attention you already know.

What is ViLBERT, in plain words?

The problem

Words and image regions are very different kinds of input. A word embedding is a learned lookup that BERT has already polished on billions of words; a region feature is 2,048 numbers from an object detector. Throwing them into one transformer (the single-stream approach) forces both through the same weights at every layer, and the image tokens can disturb the language knowledge that BERT spent so long learning. We would like each modality to be processed in its own way, at its own depth, and still let the two exchange information wherever they need to.

The idea

ViLBERT is a two-stream multimodal model. A text stream (initialised from BERT) and an image stream (over region features) run side by side. At chosen depths they are joined by co-attentional transformer layers: the text stream's queries attend over the image stream's keys and values, and at the same time the image's queries attend over the text. It is cross-attention in both directions at once.

How it works

  1. Text: BERT tokens. Image: an [IMG] token plus one token per detected region, with its box position.
  2. Each stream runs its own transformer layers.
  3. At a Co-TRM layer the streams swap keys and values, so each attends to the other.
  4. Pre-train on image–caption pairs; read off [CLS] and [IMG] for tasks.

An everyday picture

Two experts reviewing a news photo and its caption: a picture editor and a copy editor. Each works at their own desk with their own skills. Every so often they meet: the copy editor asks "where is the dog?", the picture editor asks "what is this red thing called?". Then they go back to their desks with what they learned.

Good at
  • Keeps BERT's language layers intact
  • Each modality gets its own width and depth
  • Cross-modal attention is explicit and inspectable
Watch out for
  • More parameters and more moving parts than single-stream
  • No direct word-to-word attention inside a Co-TRM layer (it comes from the TRM layers)
  • Still relies on a frozen object detector

1Two streams, joined by co-attention

Four of the six co-attention pairs are drawn. At the top, \(h_{\text{CLS}}\odot h_{\text{IMG}}\) feeds the "do they match?" head used in pre-training.

Text stream (left): the 12 layers of BERT-base, width 768, starting from BERT's pre-trained weights. Its input is the usual \([\text{CLS}],w_1,\dots,w_n,[\text{SEP}]\).

Image stream (right): its own transformer with its own width (1,024 in the released model). Its input is a special \([\text{IMG}]\) token, the mean of all region features, followed by one token per region:

$$v_j=W_ff_j+W_bb_j,\qquad b_j=\Big(\tfrac{x_1}{W},\tfrac{y_1}{H},\tfrac{x_2}{W},\tfrac{y_2}{H},\tfrac{\text{box area}}{\text{image area}}\Big)$$

Regions have no natural order, so instead of a position index each one carries its 5-number box location \(b_j\).

Co-TRM layers (the crossing arrows) connect the streams. In the released model the image stream has 6 layers, each paired by co-attention with one of the last 6 text layers, so the text gets 6 layers of language-only processing first. Between Co-TRM layers each stream also has ordinary self-attention (TRM) layers to mix information within the modality.

Which scores does each design compute?

Lay all tokens out as one long sequence, text first, then image. Self-attention over it fills all four blocks of the score matrix. A Co-TRM layer fills only the two cross blocks; the TRM layers in each stream fill the two diagonal blocks, separately. Same ingredients, organised differently.

Weights in the two maps come from simple hand-set rules (words look at the regions they name, function words look at the [IMG] summary, regions look back at the words that name them) to show the pattern; they are not from a trained network.

3The Co-TRM layer, step by step

A standard transformer layer is: multi-head self-attention, add and normalise, feed-forward, add and normalise. A Co-TRM layer changes exactly one thing: in the attention step, each stream takes its keys and values from the other stream.

Write \(H_W\) for the text states (\(n\times d_W\)) and \(H_V\) for the image states (\(m\times d_V\)). Each stream has its own projection matrices.

Text attends to image. Queries from text, keys and values from image:

$$\tilde H_W=\operatorname{softmax}\!\Big(\frac{(H_WW_Q^{W})(H_VW_K^{V})^\top}{\sqrt{d}}\Big)H_VW_V^{V}$$

Image attends to text. The mirror image:

$$\tilde H_V=\operatorname{softmax}\!\Big(\frac{(H_VW_Q^{V})(H_WW_K^{W})^\top}{\sqrt{d}}\Big)H_WW_V^{W}$$

Each stream keeps its own residual. \(H_W\leftarrow\operatorname{LN}(H_W+\tilde H_W)\), then a text feed-forward network; \(H_V\leftarrow\operatorname{LN}(H_V+\tilde H_V)\), then an image feed-forward network. So a word's vector stays a word's vector, now enriched with what it found in the image, and vice versa.

The attention matrices have shapes \(n\times m\) and \(m\times n\), so the two streams may have different lengths and (with suitable \(W_Q,W_K\)) different widths.

Algorithm: one co-attentional transformer (Co-TRM) layer
  1. input text states \(H_W\) (\(n\) tokens), image states \(H_V\) (\(m\) tokens)
  2. \(Q_W,K_W,V_W\leftarrow\) projections of \(H_W\) text weights
  3. \(Q_V,K_V,V_V\leftarrow\) projections of \(H_V\) image weights
  4. \(\tilde H_W\leftarrow\operatorname{softmax}(Q_WK_V^\top/\sqrt d)\,V_V\) text asks, image answers
  5. \(\tilde H_V\leftarrow\operatorname{softmax}(Q_VK_W^\top/\sqrt d)\,V_W\) image asks, text answers
  6. \(H_W\leftarrow\operatorname{LN}(H_W+\tilde H_W)\); \(H_V\leftarrow\operatorname{LN}(H_V+\tilde H_V)\) own residual
  7. \(H_W\leftarrow\operatorname{LN}(H_W+\operatorname{FFN}_W(H_W))\); \(H_V\leftarrow\operatorname{LN}(H_V+\operatorname{FFN}_V(H_V))\)
  8. return \(H_W,H_V\) next: a TRM self-attention layer in each stream
Going deeper: why steps 4 and 5 use the old states, and what multi-head adds

Both cross-attentions read \(H_W\) and \(H_V\) from before the layer, so they can run in parallel and neither direction gets a head start. If the text were updated first and the image then attended to the updated text, information could bounce text → image → text within one layer, and the order would matter.

As everywhere else, attention is multi-head: with 8 heads, each head has its own \(W_Q,W_K,W_V\) of width \(d/8\) and can ask a different question of the other modality (one head finds the object a noun names, another finds the colour an adjective describes). The heads' outputs are concatenated and mixed by \(W_O\) before the residual add.

Compared with one single-stream layer over \(n+m\) tokens, a Co-TRM layer computes \(2nm\) scores instead of \((n+m)^2\): it skips the within-modality scores, which the TRM layers provide separately.

4Pre-training: masked multimodal modelling and alignment

ViLBERT is pre-trained on Conceptual Captions, about 3 million images with captions scraped from alt-text on the web. Like VisualBERT, it masks words and checks whether caption and image match. Unlike VisualBERT, it also masks image regions and asks the model to say what was there.

Masked region: what was in this box?

Tap a region in the list to mask it: its features are replaced by zeros, so the model has to infer it from the caption and the other regions. The target is the detector's own class distribution for that box.

Alignment: do they belong together?

Algorithm: ViLBERT pre-training step
  1. input regions \(f_{1..m}\) with boxes \(b_{1..m}\), a caption \(w_{1..n}\) that is the true one with probability \(\tfrac12\)
  2. image tokens: \([\text{IMG}]\) (mean feature), then \(v_j\leftarrow W_ff_j+W_bb_j\)
  3. text tokens: \([\text{CLS}],w_1..w_n,[\text{SEP}]\) as in BERT
  4. mask about 15% of words and 15% of regions masked region features → 0, 90% of the time
  5. run both streams through their TRM and Co-TRM layers they exchange information
  6. \(\mathcal L_{\text{word}}\leftarrow-\sum\log p(w_i\mid h_i)\) over masked words
  7. \(\mathcal L_{\text{region}}\leftarrow\sum\operatorname{KL}\big(q_{\text{det}}(\cdot\mid j)\,\|\,p(\cdot\mid h_j)\big)\) over masked regions
  8. \(\mathcal L_{\text{align}}\leftarrow\) cross-entropy of \(\sigma\big(u^\top(h_{\text{IMG}}\odot h_{\text{CLS}})\big)\) against "caption is true"
  9. update all weights to reduce the sum masking losses only on true pairs
Going deeper: why predict a class distribution, and why multiply [IMG] and [CLS]

Regions are not words. A masked word has one right answer from a fixed vocabulary. A masked region's 2,048 features are continuous and noisy, so regressing them exactly is a poor target. ViLBERT instead asks for the detector's own soft opinion about the box, a distribution \(q_{\text{det}}\) over its 1,600 Visual Genome classes, and minimises the KL divergence \(\sum_cq_{\text{det}}(c)\log\frac{q_{\text{det}}(c)}{p(c)}\). If the detector was unsure (dog 0.6, cat 0.3), the model is not punished for being unsure in the same way.

Alignment from two summaries. In a two-stream model there is no single token that has read both modalities from the start, so the alignment head combines the summaries of both streams. The element-wise product \(h_{\text{IMG}}\odot h_{\text{CLS}}\) is large in the dimensions where both agree, and a linear layer turns it into an "aligned or not" score. When the caption is a random one, the masked-word and masked-region losses are switched off, because the text is no evidence for the image.

The pre-trained model is then fine-tuned for visual question answering, visual commonsense reasoning, referring expressions (find the box for "the man on the left") and caption-based image retrieval, where it improved on task-specific models; its retrieval works even zero-shot, straight from the alignment head.

Later work (UNITER, Oscar) found that with enough data a single stream does as well or better, which is why most current models are closer to VisualBERT's design. But the Co-TRM layer survived: cross-attention between a language model and a vision encoder is exactly how Flamingo lets a frozen language model look at images, how BLIP-2's Q-Former reads a frozen ViT, and how text prompts steer image generators. 6The same thing in Python

import torch, torch.nn as nn

class CoTRM(nn.Module):
    """One co-attentional transformer layer: each stream attends to the other."""
    def __init__(self, dw=768, dv=1024, heads=8):
        super().__init__()
        self.w_from_v = nn.MultiheadAttention(dw, heads, kdim=dv, vdim=dv, batch_first=True)  # text asks image
        self.v_from_w = nn.MultiheadAttention(dv, heads, kdim=dw, vdim=dw, batch_first=True)  # image asks text
        self.ln_w1, self.ln_w2 = nn.LayerNorm(dw), nn.LayerNorm(dw)
        self.ln_v1, self.ln_v2 = nn.LayerNorm(dv), nn.LayerNorm(dv)
        self.ff_w = nn.Sequential(nn.Linear(dw, 4*dw), nn.GELU(), nn.Linear(4*dw, dw))
        self.ff_v = nn.Sequential(nn.Linear(dv, 4*dv), nn.GELU(), nn.Linear(4*dv, dv))
    def forward(self, Hw, Hv):
        aw, Aw = self.w_from_v(Hw, Hv, Hv)       # queries: text; keys, values: image (old states)
        av, Av = self.v_from_w(Hv, Hw, Hw)       # queries: image; keys, values: text (old states)
        Hw = self.ln_w1(Hw + aw); Hv = self.ln_v1(Hv + av)
        Hw = self.ln_w2(Hw + self.ff_w(Hw)); Hv = self.ln_v2(Hv + self.ff_v(Hv))
        return Hw, Hv, Aw, Av

Hw = torch.randn(1, 12, 768)    # [CLS] + 10 words + [SEP]
Hv = torch.randn(1, 37, 1024)   # [IMG] + 36 regions
Hw, Hv, Aw, Av = CoTRM()(Hw, Hv)
print(Aw.shape, Av.shape)            # (1, 12, 37) and (1, 37, 12)
