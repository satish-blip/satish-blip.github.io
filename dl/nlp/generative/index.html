Generative models: learning to make new data

A classifier learns \(p(y\mid x)\): given a picture, which label? A generative model learns \(p(x)\) itself, well enough to draw new samples that look like the training data. Four ideas got us from blurry digits to photorealistic images: the autoencoder, the variational autoencoder, the generative adversarial network and the diffusion model. Each one trains live below on two-dimensional data, where you can see every sample, every failure and every trick, because the maths is identical to the image case, only the number of dimensions changes.

What is a generative model, in plain words?

The problem

Real data, such as faces, lie in a tiny, curved region of a huge space: almost every possible grid of pixel values is static, not a face. To generate, a model must learn where that region is and how probable each part of it is, from examples alone, with no labels saying what a good face is.

The idea

Start from something easy to sample, random noise \(z\sim\mathcal N(0,I)\), and learn a network that turns it into data. The four families differ in how that network is trained: by reconstructing data through a bottleneck (autoencoder, VAE), by fooling a critic (GAN), or by learning to undo noise one small step at a time (diffusion).

How it works

  1. Pick a simple distribution to start from: Gaussian noise.
  2. Pick a network that maps noise to data, in one step or many.
  3. Pick a training signal: reconstruction, an adversary, or denoising.
  4. Train on examples; sample by drawing noise and running the network.
  5. Steer it with a condition (a class, a text prompt) and guidance.

An everyday picture

An art forger and an inspector (GAN): the forger improves until the inspector cannot tell. A sketch artist who must describe each face in five numbers and redraw it from them (autoencoder). A restorer who has seen thousands of photographs slowly fade into grain and learns to reverse each tiny step of fading, so that, given pure grain, they can “restore” a photograph that never existed (diffusion).

Good at
  • Images, audio, molecules and text from noise or a prompt
  • Learning compact representations without labels
  • Filling in missing data, super-resolution, editing
Watch out for
  • GANs are unstable and can collapse to a few outputs
  • VAEs blur; diffusion is slow to sample without tricks
  • Memorised training data, bias and misuse (deepfakes)

1Autoencoder: squeeze through a bottleneck

A wavy curve in 2-D goes through an encoder to a code \(z\), and a decoder tries to rebuild it. The line shows everything the decoder can draw as \(z\) sweeps its range.

datareconstructiondecoder output as z sweeps

An autoencoder is two networks trained together: an encoder \(f_\phi\) that compresses \(x\) into a short code \(z=f_\phi(x)\), and a decoder \(g_\theta\) that rebuilds \(\hat x=g_\theta(z)\). The only training signal is reconstruction error,

$$\mathcal L(\phi,\theta)=\frac1n\sum_{i=1}^n\big\lVert x_i-g_\theta(f_\phi(x_i))\big\rVert^2 .$$

With a code as large as the input, the network can learn the identity and nothing interesting happens. The bottleneck forces it to keep only what matters. The wave is a one-dimensional curve drawn in two dimensions, so a code of size 1 is enough: the encoder learns roughly “how far along the curve”, and the decoder's sweep traces the curve itself. (On a tightly wound curve such as a swiss roll the same network often gets stuck folding the curve onto itself: a bottleneck forces a choice, not always a good one.) That code is a coordinate system on the data, a latent space. A linear autoencoder with squared error learns the same subspace as PCA; non-linear layers let it follow curves.

Can we generate with it? Only partly. The codes of training points occupy some region of \(z\), but nothing makes that region tidy or tells us how to sample it, and decoding a code outside it gives nonsense (watch where the sweep line leaves the data at its ends). The VAE fixes exactly this.

Going deeper: denoising and sparse autoencoders

A denoising autoencoder (Vincent et al., 2008) is fed a corrupted \(\tilde x\) and must output the clean \(x\); it cannot copy, so it learns the data's structure even without a narrow bottleneck. This idea, learning to remove noise, returns as the heart of diffusion models. A sparse autoencoder uses a wide code with a penalty that keeps most units at zero; they are used today to find interpretable features inside language models. Masked autoencoders for images are covered in self-supervised learning.

Adapted from: Hinton and Salakhutdinov, Reducing the dimensionality of data with neural networks (Science, 2006); Goodfellow, Bengio and Courville, Deep Learning, ch. 14.

2Variational autoencoder: a latent space you can sample

Eight clusters in 2-D, a 2-D latent space. Red points are brand-new samples: draw \(z\sim\mathcal N(0,I)\), decode. Turn β up and the latent space gets tidier while the samples get blurrier.

datanew samples from the prior

Above: where each training point's code μ(x) lands in latent space, coloured by its cluster, with the unit circle of the prior.

A variational autoencoder makes the latent space a probability model. The decoder defines \(p_\theta(x\mid z)\) and the prior is \(p(z)=\mathcal N(0,I)\), so sampling is easy: draw \(z\), decode. Training should maximise \(\log p_\theta(x)\), which is intractable, so the encoder outputs a Gaussian guess \(q_\phi(z\mid x)=\mathcal N(\mu_\phi(x),\sigma^2_\phi(x))\) for which codes could have produced \(x\), and we maximise the evidence lower bound:

$$\log p_\theta(x)\ \ge\ \underbrace{\mathbb E_{q_\phi(z\mid x)}\big[\log p_\theta(x\mid z)\big]}_{\text{reconstruct}}-\beta\,\underbrace{\mathrm{KL}\big(q_\phi(z\mid x)\,\Vert\,\mathcal N(0,I)\big)}_{\text{stay near the prior}}.$$

The first term is reconstruction, as before. The second, a KL divergence with a closed form for Gaussians, \(\tfrac12\sum_j(\mu_j^2+\sigma_j^2-\log\sigma_j^2-1)\), pulls every code distribution towards the prior, so the codes fill the region we will sample from, without gaps.

The reparameterisation trick makes this trainable: instead of sampling \(z\) (which has no gradient), write \(z=\mu+\sigma\odot\varepsilon\) with \(\varepsilon\sim\mathcal N(0,I)\), so gradients flow through \(\mu\) and \(\sigma\). In the lab, the red samples cover the clusters but also fall between them: the decoder must map a smooth Gaussian onto eight separate blobs, and the regions between codes decode to in-between points. That is the 2-D version of the VAE's famous blurriness. Lower β sharpens samples but leaves holes in the latent space; higher β smooths the space and blurs everything.

Going deeper: why the bound holds, and VQ-VAE

For any \(q\), \(\log p(x)=\text{ELBO}+\mathrm{KL}\big(q(z\mid x)\,\Vert\,p(z\mid x)\big)\), and a KL is never negative, so the ELBO is a lower bound, tight when \(q\) equals the true posterior. Training the encoder pushes \(q\) towards the posterior; training the decoder raises the likelihood.

The VQ-VAE (van den Oord et al., 2017) replaces the Gaussian code with the nearest vector from a learnt codebook, giving discrete tokens. Those tokens, and VAE encoders in general, are what latent diffusion and many image and audio generators work in (section 5).

Adapted from: Kingma and Welling, Auto-Encoding Variational Bayes (2013); Higgins et al., β-VAE (ICLR 2017); Kingma and Welling, An Introduction to Variational Autoencoders (2019).

3GAN: a forger and an inspector

The generator turns noise into points; the discriminator (background: bright where it thinks “real”) tries to tell them from the data. Watch them chase each other, and watch for clusters the generator never finds.

datagenerated

A generative adversarial network drops the encoder and the likelihood altogether. A generator \(G\) maps noise to samples; a discriminator \(D\) outputs the probability that its input is real. They play a minimax game:

$$\min_G\max_D\ \ \mathbb E_{x\sim p_{\text{data}}}\big[\log D(x)\big]+\mathbb E_{z\sim\mathcal N(0,I)}\big[\log\big(1-D(G(z))\big)\big].$$

For a fixed \(G\) the best discriminator is \(D^*(x)=p_{\text{data}}(x)/(p_{\text{data}}(x)+p_G(x))\), and plugging it in shows the generator is minimising the Jensen–Shannon divergence between the data and its own distribution, which is zero only when they match. In practice the generator maximises \(\log D(G(z))\) instead (the “non-saturating” loss), which gives strong gradients early on when \(D\) easily rejects its samples. The only information \(G\) ever receives is the gradient of \(D\)'s opinion, back-propagated through \(D\) into its samples.

Algorithm: one GAN training step
  1. input data batch \(\{x_i\}\), noise batch \(\{z_i\}\), networks \(G, D\)
  2. \(\tilde x_i\leftarrow G(z_i)\) fakes
  3. update \(D\) to raise \(\log D(x_i)+\log(1-D(\tilde x_i))\) G frozen
  4. new noise; \(\tilde x_i\leftarrow G(z_i)\)
  5. update \(G\) to raise \(\log D(\tilde x_i)\), gradients flowing through \(D\) D frozen
  6. repeat until samples look right (there is no loss that says when)

GANs give the sharpest samples of the classic models, but training is a balancing act. Mode collapse is the classic failure: the generator finds a few outputs that fool the discriminator and stops exploring, so some clusters never appear. Raise the learning rate in the lab and the two networks start to oscillate instead of converging.

Going deeper: Wasserstein GANs and StyleGAN

When the data and generator distributions do not overlap, the Jensen–Shannon divergence is constant and gives no useful gradient. The Wasserstein GAN (Arjovsky et al., 2017) replaces it with the earth-mover distance, estimated by a critic kept smooth by a gradient penalty (Gulrajani et al., 2017), which gives more stable training and a loss that tracks quality. StyleGAN (Karras et al., 2019) feeds the noise through a mapping network and injects it at every resolution, producing the photorealistic faces that made GANs famous. Diffusion models have since overtaken GANs for most image generation, but GAN-style adversarial losses survive inside them, for example to sharpen the VAE decoder of latent diffusion.

Adapted from: Goodfellow et al., Generative Adversarial Nets (2014); Arjovsky, Chintala and Bottou, Wasserstein GAN (2017); Metz et al., Unrolled GANs (2017) for the eight-Gaussian test.

4Diffusion: learn to remove noise

Two moons, each moon a class. The forward process buries the data in noise over T = 40 steps (slide t). A network learns to predict the added noise; running it backwards from pure noise draws new moons.

moon Amoon Bgenerated samples

A diffusion model turns generation into many small denoising problems. The forward process is fixed, not learnt: at each step add a little Gaussian noise, with variances \(\beta_1,\dots,\beta_T\) set by a noise schedule. With \(\alpha_t=1-\beta_t\) and \(\bar\alpha_t=\prod_{s\le t}\alpha_s\), we can jump straight to any step:

$$x_t=\sqrt{\bar\alpha_t}\,x_0+\sqrt{1-\bar\alpha_t}\,\varepsilon,\qquad \varepsilon\sim\mathcal N(0,I).$$

By \(t=T\) the data is indistinguishable from pure noise. The reverse process is learnt. A network \(\varepsilon_\theta(x_t,t)\) is trained to predict the noise that was added, a plain regression:

$$\mathcal L(\theta)=\mathbb E_{x_0,\,t,\,\varepsilon}\Big[\big\lVert\varepsilon-\varepsilon_\theta\big(\sqrt{\bar\alpha_t}x_0+\sqrt{1-\bar\alpha_t}\,\varepsilon,\ t\big)\big\rVert^2\Big].$$

To generate, start from \(x_T\sim\mathcal N(0,I)\) and step backwards, each time removing the predicted noise and adding a little fresh noise:

$$x_{t-1}=\frac{1}{\sqrt{\alpha_t}}\Big(x_t-\frac{\beta_t}{\sqrt{1-\bar\alpha_t}}\,\varepsilon_\theta(x_t,t)\Big)+\sqrt{\beta_t}\,z .$$
Algorithm: DDPM training and sampling
  1. train: pick \(x_0\) from the data, \(t\sim\{1..T\}\), \(\varepsilon\sim\mathcal N(0,I)\)
  2. \(x_t\leftarrow\sqrt{\bar\alpha_t}x_0+\sqrt{1-\bar\alpha_t}\,\varepsilon\)
  3. gradient step on \(\lVert\varepsilon-\varepsilon_\theta(x_t,t)\rVert^2\)
  4. sample: \(x_T\sim\mathcal N(0,I)\)
  5. for \(t=T,\dots,1\): \(x_{t-1}\leftarrow\frac{1}{\sqrt{\alpha_t}}\big(x_t-\frac{\beta_t}{\sqrt{1-\bar\alpha_t}}\varepsilon_\theta(x_t,t)\big)+\sqrt{\beta_t}\,z\)
  6. return \(x_0\)

Why does this work so well? Each step only has to undo a little noise, which is an easy, stable regression problem: no adversary, no posterior to approximate, and no mode collapse, because every training point is a target. Predicting the noise is equivalent to estimating the score \(\nabla_x\log p_t(x)\), the direction towards higher data density at noise level \(t\); sampling follows those arrows downhill in noise.

Going deeper: faster sampling, score matching and flow matching

Hundreds of network calls per sample is slow. DDIM (Song et al., 2021) takes deterministic, larger steps with the same trained network, giving good samples in 20–50 steps. The continuous-time view (Song et al., 2021) writes the forward process as a stochastic differential equation whose reverse depends only on the score, which unifies diffusion with score matching. Flow matching and rectified flows (Lipman et al., 2023; Liu et al., 2023) learn a velocity field along straight paths from noise to data, used in recent image models; consistency and distillation methods cut sampling to a handful of steps.

Adapted from: Sohl-Dickstein et al., Deep Unsupervised Learning using Nonequilibrium Thermodynamics (2015); Ho, Jain and Abbeel, Denoising Diffusion Probabilistic Models (2020), algorithms 1 and 2.

5Classifier-free guidance

The same diffusion model was trained with its class label, and with the label hidden 20% of the time. Ask for one moon and turn up the guidance weight w.

Uses the network trained in section 4; retraining there updates this lab.

To control what a diffusion model draws, give the network a condition \(c\) (a class, or a text prompt embedded by a model such as CLIP or T5) as an extra input: \(\varepsilon_\theta(x_t,t,c)\). On its own, conditioning is often too weak: samples drift between classes or only loosely match the prompt.

Classifier-free guidance trains one network to be both conditional and unconditional, by replacing \(c\) with a “null” token for a random 10–20% of training examples. At sampling time, run it both ways and extrapolate away from the unconditional prediction:

$$\tilde\varepsilon=(1+w)\,\varepsilon_\theta(x_t,t,c)-w\,\varepsilon_\theta(x_t,t,\varnothing).$$

The difference between the two predictions points towards “more like \(c\)”; scaling it up by \(w\) exaggerates that. In score terms it samples from a sharpened \(p(x)\,p(c\mid x)^{w+1}\). Raise \(w\) in the lab: samples concentrate on the requested moon and pull towards its most typical region, at the cost of variety. Text-to-image systems use \(w\) around 3–10: higher gives closer prompt match and less diversity.

Latent diffusion

Running diffusion on a 1024×1024×3 image is expensive. Latent diffusion (the design behind Stable Diffusion) first trains a VAE-like autoencoder that compresses images about 8× in each direction into a latent grid, then runs the whole diffusion process in that latent space, with a U-Net or a transformer as \(\varepsilon_\theta\) and the text fed in through cross-attention. The decoder turns the final latent back into pixels. So all four ideas on this page meet in one system: an autoencoder for compression, VAE-style regularisation of its latent space, an adversarial loss to keep the decoder sharp, and diffusion with guidance to generate.

Adapted from: Ho and Salimans, Classifier-Free Diffusion Guidance (2022); Rombach et al., High-Resolution Image Synthesis with Latent Diffusion Models (CVPR 2022).

6The same thing in Python

A VAE loss with the reparameterisation trick, a complete 2-D DDPM with classifier-free guidance in PyTorch, and text-to-image with Hugging Face diffusers.

# pip install torch scikit-learn diffusers transformers accelerate
import torch, torch.nn as nn, torch.nn.functional as F
from sklearn.datasets import make_moons

# ---- 1. VAE loss: reconstruction + beta * KL, with the reparameterisation trick ----
def vae_loss(encoder, decoder, x, beta=1.0):
    mu, logvar = encoder(x).chunk(2, dim=-1)
    z = mu + torch.exp(0.5 * logvar) * torch.randn_like(mu)          # z = mu + sigma * eps
    recon = F.mse_loss(decoder(z), x, reduction="sum") / len(x)
    kl = -0.5 * torch.sum(1 + logvar - mu**2 - logvar.exp()) / len(x)
    return recon + beta * kl

# ---- 2. DDPM on two moons, conditioned on the moon, with classifier-free guidance ----
X, y = make_moons(4000, noise=0.05)
X = torch.tensor((X - X.mean(0)) / X.std(0), dtype=torch.float32); y = torch.tensor(y)

T = 100
beta = torch.linspace(1e-4, 0.05, T); alpha = 1 - beta; abar = torch.cumprod(alpha, 0)

class EpsNet(nn.Module):
    def __init__(self, n_classes=2, d=128):
        super().__init__()
        self.emb = nn.Embedding(n_classes + 1, 16)                      # index n_classes = "no label"
        self.net = nn.Sequential(nn.Linear(2 + 16 + 2, d), nn.SiLU(), nn.Linear(d, d), nn.SiLU(), nn.Linear(d, 2))
    def forward(self, x, t, c):
        tf = torch.stack([torch.sin(t / T * 3.14), torch.cos(t / T * 3.14)], -1)
        return self.net(torch.cat([x, self.emb(c), tf], -1))

model = EpsNet(); opt = torch.optim.Adam(model.parameters(), lr=1e-3)
for step in range(5000):
    i = torch.randint(0, len(X), (256,)); x0, c = X[i], y[i].clone()
    c[torch.rand(256) < 0.2] = 2                                         # hide the label 20% of the time
    t = torch.randint(0, T, (256,)); eps = torch.randn_like(x0)
    xt = abar[t].sqrt()[:, None] * x0 + (1 - abar[t]).sqrt()[:, None] * eps
    loss = F.mse_loss(model(xt, t.float(), c), eps)
    opt.zero_grad(); loss.backward(); opt.step()

@torch.no_grad()
def sample(n, cls, w=2.0):
    x = torch.randn(n, 2); c = torch.full((n,), cls); null = torch.full((n,), 2)
    for t in reversed(range(T)):
        tt = torch.full((n,), float(t))
        eps = (1 + w) * model(x, tt, c) - w * model(x, tt, null)       # classifier-free guidance
        x = (x - beta[t] / (1 - abar[t]).sqrt() * eps) / alpha[t].sqrt()
        if t > 0: x = x + beta[t].sqrt() * torch.randn_like(x)
    return x

print(sample(500, cls=0)[:5])

# ---- 3. Text-to-image with a pretrained latent diffusion model ----
from diffusers import DiffusionPipeline
pipe = DiffusionPipeline.from_pretrained("stabilityai/stable-diffusion-2-1-base")  # needs a GPU for speed
image = pipe("a watercolour fox in a snowy forest", guidance_scale=7.5, num_inference_steps=30).images[0]
image.save("fox.png")
