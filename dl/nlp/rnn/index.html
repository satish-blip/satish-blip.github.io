Recurrent networks: reading in order

Text is a sequence: the meaning of a word depends on what came before it. A recurrent neural network reads one token at a time and carries a running summary, its hidden state, from each step to the next. The same small set of weights is reused at every step, so it can read sequences of any length.

What is a recurrent neural network, in plain words?

The problem

A sentence, a sound clip or a price history has an order, and its length changes from example to example. A plain network takes a fixed-size input and has no idea that word 5 comes after word 4. We want a model that reads one item at a time, carries forward what it has seen so far, and uses the same weights at every step so it works for any length.

The idea

An RNN reads a sequence one item at a time and keeps a running summary, its hidden state. At each step it mixes the new input with the old summary using the same weights, so it can handle sequences of any length. It is trained by backpropagation through time, which runs the chain rule backwards through every step.

How it works

  1. Start with a hidden state of zeros.
  2. For each token: new state = tanh(input weights × token + recurrent weights × old state + bias).
  3. Read predictions off the hidden state.
  4. Train with BPTT; clip big gradients, and expect the vanishing gradient for long gaps.

An everyday picture

Reading a novel while keeping a one-line note of the plot so far, rewriting the note after every sentence. Anything that falls off the note is gone.

Good at
  • Handles any sequence length with fixed parameters
  • Natural fit for streaming input
  • Small and simple
Watch out for
  • Forgets long-range information (vanishing gradients)
  • Must run step by step, so it is slow to train
  • Largely replaced by transformers for text

Hidden state after each word

Rows are time steps, columns are the 6 hidden units. Purple positive, orange negative. Every row depends on all the words above it.

Step

The same \(W_{xh}\), \(W_{hh}\) and \(b\) are used at every step: that weight sharing is what "recurrent" means.

Algorithm: RNN forward pass and backpropagation through time
  1. input sequence \(x_1..x_T\), targets \(y_1..y_T\), weights \(W_{xh},W_{hh},W_{hy}\)
  2. \(h_0\leftarrow0\)
  3. for \(t=1\) to \(T\) do forward, left to right
  4. \(h_t\leftarrow\tanh(W_{xh}x_t+W_{hh}h_{t-1}+b)\) same weights every step
  5. \(\hat y_t\leftarrow\operatorname{softmax}(W_{hy}h_t)\); \(\mathcal L\mathrel{+}=-\log\hat y_t[y_t]\)
  6. \(g_h\leftarrow0\)
  7. for \(t=T\) down to 1 do backward, right to left
  8. \(g_h\leftarrow g_h+W_{hy}^\top(\hat y_t-y_t)\) error from this step’s output
  9. \(\delta\leftarrow g_h\odot(1-h_t^2)\); add \(\delta x_t^\top\) to \(\nabla W_{xh}\), \(\delta h_{t-1}^\top\) to \(\nabla W_{hh}\)
  10. \(g_h\leftarrow W_{hh}^\top\delta\) pass the error one step back in time
  11. return the summed gradients, then take a step clip their norm first
Going deeper: why long-range gradients vanish or explode

The error at step \(T\) reaches step \(t\) through the chain \(\frac{\partial h_T}{\partial h_t}=\prod_{k=t+1}^{T}\operatorname{diag}(1-h_k^2)\,W_{hh}\). That is the same matrix \(W_{hh}\) multiplied in \(T-t\) times. If its largest singular value times the typical tanh slope is below 1, the product shrinks geometrically, and the model cannot learn that word 3 matters for word 40. If it is above 1, the product blows up and one update can wreck the weights.

Exploding is easy to treat: gradient clipping rescales \(\nabla\) whenever \(\lVert\nabla\rVert\) exceeds a threshold. Vanishing is the deep problem, and it is what the LSTM's additive cell state (next page) and, later, attention were invented to fix. Truncated BPTT, which only backpropagates for the last few dozen steps, accepts the limitation to save memory and time.

2Can it remember? A memory test, trained live

The task: a sequence of \(T\) random bits (+1 or −1) is fed in one at a time. A flag marks the first step. After the last bit the network must answer: what was the first bit? Everything in between is noise to be ignored.

The answer only depends on step 1, so the error signal must travel back through all \(T\) steps to reach it. Short sequences (\(T\) up to about 15) are learned in seconds. At \(T=30\) a plain RNN usually stays near a coin flip: by the time the gradient reaches step 1 it has shrunk by dozens of orders of magnitude (chart below). Now and then an initialisation gets lucky and finds a "latch" early, so try a few with New seed.

The LSTM and GRU page runs the same test with gated cells, which usually pass it within a few hundred steps at \(T=30\).

3Vanishing and exploding gradients

\(\lVert\partial h_{50}/\partial h_t\rVert\) for a random RNN with 16 tanh units, averaged over 5 random inputs, log scale. Below about 1 it collapses; above, tanh saturation fights the growth but gradients can still blow up.

Backpropagation through time multiplies one Jacobian per step:

$$\frac{\partial h_T}{\partial h_t}=\prod_{k=t+1}^{T}\operatorname{diag}\!\big(1-h_k^2\big)\,W_{hh}$$

If the factors shrink vectors (largest singular value of \(W_{hh}\) times the tanh slope below 1), the product vanishes exponentially: the network cannot learn anything that depends on the distant past. If they stretch vectors it can explode, producing huge, destabilising updates.

  • Exploding: fixed by gradient clipping: if \(\lVert g\rVert>\tau\), rescale \(g\leftarrow\tau g/\lVert g\rVert\). Used in section 2 (\(\tau=5\)).
  • Vanishing: needs a change of architecture: an additive memory path whose Jacobian is close to the identity. That is the LSTM cell state, the same trick as a residual connection, and ultimately attention, which connects every step to every other step directly.

5The maths

Forward

$$\begin{aligned}h_t&=\tanh\big(W_{xh}x_t+W_{hh}h_{t-1}+b_h\big)\\ \hat y_t&=\operatorname{softmax}(W_{hy}h_t+b_y)\end{aligned}$$

\(h_0=0\). For classification of the whole sequence use only the last \(h_T\); for language modelling predict at every step and sum the losses.

Parameters: \(h(d+h+1)+o(h+1)\) for input size \(d\), hidden size \(h\), output size \(o\), whatever the sequence length.

Backpropagation through time

$$\begin{aligned}\delta_t&=\frac{\partial\mathcal L}{\partial h_t}=W_{hy}^\top(\hat y_t-y_t)+W_{hh}^\top\big[(1-h_{t+1}^2)\odot\delta_{t+1}\big]\\ \frac{\partial\mathcal L}{\partial W_{hh}}&=\sum_t\big[(1-h_t^2)\odot\delta_t\big]h_{t-1}^\top\end{aligned}$$

Unroll the network over the sequence, run ordinary backpropagation, and add up the gradients of the shared weights over all steps. Truncated BPTT stops after a fixed number of steps to save memory on long texts.

6The same thing in Python (PyTorch)

rnn = nn.RNN(input_size=32, hidden_size=64, batch_first=True)    # tanh RNN
head = nn.Linear(64, vocab_size)
out, h_last = rnn(embed(token_ids))       # out: (batch, T, 64), one hidden state per step
loss = F.cross_entropy(head(out).transpose(1, 2), next_ids)
loss.backward()                           # backpropagation through time
torch.nn.utils.clip_grad_norm_(params, max_norm=5.0)   # tame exploding gradients
