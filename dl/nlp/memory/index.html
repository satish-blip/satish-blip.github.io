Memory in RNNs: LSTM and GRU

A plain RNN overwrites its whole hidden state at every step, so old information fades and its gradient vanishes. Gated cells add a separate memory lane that is changed only by small, deliberate edits: forget a little, write a little, read a little. That simple change lets them carry information across hundreds of steps.

What are LSTM and GRU, in plain words?

The problem

A plain RNN overwrites its whole memory at every step, so by word 40 the information from word 3 has been squashed through 37 tanh layers, and the gradient that would teach it to remember has faded to nothing. We want a memory that, by default, simply keeps what it has, and that changes only when the network decides it should.

The idea

LSTMs and GRUs are RNNs with gates: small sigmoid switches, learned from data, that decide what to forget, what to write and what to read. The LSTM keeps a separate cell state that is updated by adding, not multiplying, so information and gradients can travel through hundreds of steps.

How it works

  1. Forget gate: how much of the old memory to keep.
  2. Input gate: how much new information to write.
  3. Output gate: how much of the memory to show as the hidden state.
  4. The GRU merges these into two gates (update and reset) and has no separate cell.

An everyday picture

A notebook with a pencil and an eraser. A plain RNN rewrites the whole page every step; an LSTM decides line by line what to erase and what to add, so an important early note can survive.

Good at
  • Remembers across long gaps
  • Trains far more reliably than a plain RNN
  • GRU gets similar results with fewer parameters
Watch out for
  • Still sequential, so slow on long texts
  • Four times the parameters of a plain RNN (LSTM)
  • Attention does long-range memory better

1The LSTM cell

The top line is the cell state \(c\): information flows along it with only a multiply (forget) and an add (write). Each gate is a sigmoid layer that reads \([h_{t-1},x_t]\) and outputs numbers between 0 (closed) and 1 (open).

$$\begin{aligned}f_t&=\sigma(W_f[h_{t-1},x_t]+b_f)&&\text{forget gate}\\ i_t&=\sigma(W_i[h_{t-1},x_t]+b_i)&&\text{input gate}\\ \tilde c_t&=\tanh(W_c[h_{t-1},x_t]+b_c)&&\text{candidate}\\ c_t&=f_t\odot c_{t-1}+i_t\odot\tilde c_t&&\text{cell state}\\ o_t&=\sigma(W_o[h_{t-1},x_t]+b_o)&&\text{output gate}\\ h_t&=o_t\odot\tanh(c_t)&&\text{hidden state}\end{aligned}$$
  • Forget gate \(f\): how much of each memory slot to keep. 1 = keep everything.
  • Input gate \(i\) and candidate \(\tilde c\): what new information to write, and how much of it.
  • Output gate \(o\): which parts of the memory to expose as \(h_t\) for this step's prediction.

Hochreiter and Schmidhuber (1997). The forget gate was added by Gers et al. (2000); initialising its bias to 1, so the cell starts by remembering, is a common trick used here too.

Algorithm: one LSTM step
  1. input new input \(x_t\), previous hidden state \(h_{t-1}\), previous cell state \(c_{t-1}\)
  2. \(u\leftarrow[h_{t-1};x_t]\) stack them into one vector
  3. \(f\leftarrow\sigma(W_fu+b_f)\) forget gate: keep how much of each memory slot?
  4. \(i\leftarrow\sigma(W_iu+b_i)\); \(\tilde c\leftarrow\tanh(W_cu+b_c)\) what to write, and how much
  5. \(c_t\leftarrow f\odot c_{t-1}+i\odot\tilde c\) the conveyor belt: add, never squash
  6. \(o\leftarrow\sigma(W_ou+b_o)\) output gate: what to reveal
  7. \(h_t\leftarrow o\odot\tanh(c_t)\)
  8. return \(h_t,c_t\) repeat for the next step
Going deeper: why the cell state is a gradient highway

Differentiate the cell update: \(\partial c_t/\partial c_{t-1}=\operatorname{diag}(f_t)\), plus small terms through the gates. There is no weight matrix and no tanh slope on this path, just the forget gate. Going back \(n\) steps multiplies by \(f_{t}\odot f_{t-1}\odot\cdots\), and when the network wants to remember it learns \(f\approx1\), so the gradient survives almost unchanged. Compare the plain RNN, where every step multiplies by \(W_{hh}^\top\operatorname{diag}(1-h^2)\).

This is the same idea as the residual connection, discovered 18 years earlier: an additive path with factor about 1. A common practical trick follows from it: initialise the forget-gate bias \(b_f\) to 1 or 2 so that \(f\) starts near 1 and the LSTM remembers by default. The GRU merges forget and input into one update gate \(z\), \(h_t=(1-z)\odot h_{t-1}+z\odot\tilde h\), which keeps the highway with fewer parameters.

2RNN versus LSTM versus GRU, trained live

The memory test from the RNN page: read \(T\) random bits and report the first one. All three cells have 12 hidden units, Adam, gradient clipping at 5, and the same data. Each uses a learning rate that works well for it (RNN and LSTM 0.01, GRU 0.03).

Typical result at \(T=30\): the LSTM solves it within a few hundred steps, the GRU a little later, the plain RNN usually never. At \(T\le10\) all three succeed. Results vary with the seed: that variation is real.

4The gradient highway

Why does the cell state keep gradients alive? Along the memory lane,

$$\frac{\partial c_t}{\partial c_{t-1}}=\operatorname{diag}(f_t)\quad\Rightarrow\quad\frac{\partial c_T}{\partial c_t}=\prod_{k=t+1}^{T}\operatorname{diag}(f_k)$$

There is no weight matrix and no squashing derivative in that product, only the forget gates. When the network decides to remember (\(f\approx1\)) the gradient passes back almost untouched, exactly like the identity path of a residual connection. In a plain RNN every step multiplies by \(\operatorname{diag}(1-h^2)W_{hh}\), which usually shrinks it.

The chart shows \(\lVert\partial\mathcal L/\partial h_t\rVert\) on the latest training batch of each racer, from step 1 (left) to step \(T\). Once a racer has solved the task its loss, and so every gradient, becomes tiny; compare the shapes early in the race.

5The GRU, and how many parameters each cell needs

The gated recurrent unit (Cho et al. 2014) merges the cell and hidden state and uses two gates:

$$\begin{aligned}r_t&=\sigma(W_r[h_{t-1},x_t])&&\text{reset}\\ z_t&=\sigma(W_z[h_{t-1},x_t])&&\text{update}\\ \tilde h_t&=\tanh\big(W_hx_t+r_t\odot U_hh_{t-1}\big)\\ h_t&=(1-z_t)\odot\tilde h_t+z_t\odot h_{t-1}\end{aligned}$$

The update gate \(z\) plays the role of both forget and input gates (keep \(z\), write \(1-z\)); the reset gate decides how much of the past to use when proposing \(\tilde h\). Fewer parameters, often similar accuracy.

Weights per layer, ignoring the output layer. One weight block is \(h(d+h)+h\); an LSTM has 4 blocks (f, i, c̃, o), a GRU 3 (r, z, h̃), a plain RNN 1. PyTorch stores two bias vectors per block, so its counts are slightly higher.

6The same thing in Python (PyTorch)

lstm = nn.LSTM(input_size=300, hidden_size=512, num_layers=2, batch_first=True, bidirectional=True)
out, (h_n, c_n) = lstm(x)          # out: (batch, T, 2*512); h_n, c_n: final hidden and cell states
gru = nn.GRU(300, 512, batch_first=True)
out, h_n = gru(x)
sum(p.numel() for p in nn.LSTM(300, 512).parameters())   # 1,667,072 = 4 × (512·(300+512) + 2·512)
