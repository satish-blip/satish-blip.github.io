Backprop visualiser

A small network learns to separate two classes. Watch the activations of one example flow forward and its error flow back, and see how strongly each layer's weights are being pushed.

Learn: chain rule →Learn: neural nets →

Network

Circles: units, filled by their value for the selected example (blue positive, red negative). Lines: weights, thicker for larger magnitude; in the Gradients view, lines show \(|\partial L/\partial w|\) for this example and circles show each unit's error \(\delta\).

One example, step by step

Click a point on the map to choose the example, then walk the forward and backward pass.

Loss

Binary cross-entropy on all 200 points, per epoch.

Gradient flow

Average \(|\partial L/\partial W|\) per layer (log scale), from the first hidden layer (left) to the output (right). A steep drop towards the left is the vanishing-gradient problem: try 6 sigmoid layers.

Attention explorer

Type a short sentence and see who looks at whom. Each head is a pair of query and key maps built by hand from word features, so every pattern can be explained.

Learn: self-attention →

Attention matrix

Row = the word asking (query), column = the word looked at (key). Click a row.

One query

Arcs from the selected word to every word it attends to, then the softmax step by step.

All heads at once (multi-head attention)

The same sentence through every head. A transformer layer runs heads like these in parallel and concatenates their outputs.
