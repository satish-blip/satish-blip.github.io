Quick start

Your first model in four steps. Each step names the button to press.

  1. Pick a tool. New to machine learning? Start with the ML Playground. Working in insurance pricing? Start with GLM pricing. The tools are described one by one below.
  2. Load data. Every tool opens with a ready-made sample, so you can press on straight away. In the Playground, choose another sample from the Sample datasets drop-down, or drop in your own CSV under Your own data and pick the column to predict (the target).
  3. Run it. Follow the numbered stages in the left sidebar from top to bottom. In the Playground press Train & evaluate at the Model training stage; in GLM pricing press Fit GLM. Defaults are sensible, so you can change settings later.
  4. Read and explore. Check the scores, then switch the view at the top to Dependency to see how every input travels to the prediction and how much the prediction moves when you change one input. Every panel has a Learn link to the lesson behind it and a </> Code button with the matching Python.

Stuck at any point? Open ⋯ → Help in the tool’s header, or the small ? beside any setting: it says what the setting does, what turning it up or down changes, and why.

How every tool is laid out

The Playground, GLM pricing and Reserving share one layout, so once you know one you know them all.

Header

A short line under the title shows the loaded data, target and model. On the right, the ⋯ menu holds Help, the light/dark switch and Verbose / Clean (Clean folds long descriptions behind an ⓘ); the panel button opens Details, a summary of your session and an outline of the current screen. Only one side panel is open at a time: opening Details or the code drawer folds the stage sidebar.

Sidebar of stages

The numbered stages on the left are the workflow in order. Click any stage to jump to it; a tick shows what is done. The ‹ button folds the sidebar to icons to give the workspace more room.

Four views of the same model

Tabs: the stages one at a time. Workflow: drag-and-drop boxes on a canvas. Statistical: the fitted model written as equations with your numbers. Dependency: a column-by-column graph from each input to the prediction, plus what-if controls.

Panels

Each panel has to fold it away and to open it full screen (Esc closes). </> Code opens a drawer with the Python for that panel and the JavaScript that runs on the page. Learn opens the matching lesson in a new tab.

The “?” explainers

Every setting has a ?. It explains what the setting is, what a higher or lower value does to the result, what each option means and the rule of thumb behind the default.

Your data stays with you

Files are read by your browser and never uploaded. Settings, theme and folded panels are remembered on this device only. Export the settings to pick up later or on another computer.

Every feature, tool by tool

Choose a tool to see everything it can do, stage by stage.

1Import data

Nine samples (rice grains, iris, wine, breast cancer, diabetes, customer churn with messy values, house prices, two moons, sparse regression), or your own CSV by upload, paste or URL. Set each column’s type and role (feature, target or ignore) and the task (classification or regression).

2EDA: data checks and visuals

Health checks with one-click fixes (missing values, duplicates, constant columns, skew, outliers, leakage hints), column profiles, the target’s distribution, an interactive chart explorer, transforms and feature scales, correlation with VIF, and t-SNE / PCA maps of the rows.

3Preprocessing

Train / test split (random or stratified) and cross-validation, missing-value imputation, outlier clipping or removal, category encoding (one-hot or ordinal), scaling (standard, min–max, robust, max-abs) and class balancing (class weights, over-sampling, SMOTE). Every step is fitted on the training rows only, so nothing leaks.

4Feature engineering

Skew transforms (log, square root, Yeo–Johnson), polynomial and interaction features, feature selection (variance, best-k, L1, tree importance, RFE or manual) and dimensionality reduction with PCA.

5Model training

24 models written from scratch and checked against scikit-learn: linear and logistic regression, ridge, lasso, elastic net, ridge classifier, k-nearest neighbours, naive Bayes, LDA, QDA, decision trees, random forests, extra trees, AdaBoost, gradient boosting, support vector machines and regression, and kernel ridge. Every hyperparameter has a “?” explainer.

6Hyperparameter tuning

Cross-validated grid search over one or two hyperparameters with a heat map of the scores and the best setting applied in one click.

7Evaluation

Train, cross-validation and test scores; the pipeline graph (what each stage did to the data); diagnostics (confusion matrix, ROC and PR curves, calibration, threshold, residual plots); statistics (statsmodels-style OLS and logit tables); model comparison on the same pipeline; and predictions for new rows, test-set rows or a whole CSV.

8Explainability

Feature importance, permutation importance, the decision surface and learning curves. For one row at a time, use the Dependency view.

9Export

The full Python script or a Jupyter notebook, the predictions as CSV, your settings as JSON, a printable report, the experiment history, and a button that runs the exported Python in your browser (Pyodide).

VViews: Workflow, Statistical, Dependency

Workflow rebuilds the pipeline as drag-and-drop boxes with a properties panel. Statistical writes the trained model as equations: its objective, the fitted weights, tree diagrams and one test row worked through. Dependency draws a column-by-column graph (inputs → preparation → model columns → inside the model → prediction) for any row, shows what each input added (Shapley values), the swing of the prediction when only one input changes, and a what-if slider with the curve for this row and the average over many rows.

1Data

A synthetic motor portfolio with known true relativities, plus real data sets loaded on demand: medical insurance charges, health-to-motor cross-sell, the CoIL 2000 caravan set and a French motor (freMTPL2) sample. Or your own CSV. Map the exposure, claim count and claim amount columns.

2One-way analysis

Actual experience by factor with exposure bars, two-way tables and consistency over time, so you can see each factor before modelling.

3Model

Task (frequency, severity, pure premium, claim probability or a custom response), family (Poisson, quasi-Poisson, negative binomial, gamma, inverse Gaussian, log-normal, Tweedie, binomial) and link, offset and weights, factor types (categorical, banded, linear, log, quadratic, piecewise linear), base levels, level merging, interactions and ridge / lasso / elastic-net penalties.

4Relativities

Fitted relativities with 95% intervals, the coefficient table, fit statistics and “change a relativity and see what moves” (lock a level, refit the rest).

5Validation

Actual versus predicted, quantile plots, lift and double lift, Gini and ROC, residual checks, Cook’s distance and k-fold cross-validation (some marked Advanced).

6Predict

Type a policy’s details and watch its price build up from the base rate, factor by factor; compare saved models on one policy; score a CSV.

7Compare & export

Saved models side by side, F-tests and likelihood-ratio tests, checks against the CAS GLM monograph, and the statsmodels code for the whole model.

VViews and modes

Workflow, Statistical and Dependency views work as in the Playground; in the Dependency view each factor’s contribution is exact (its relativity for this policy), and the what-if control shows how the price moves when one factor changes.

Questions

Short answers to what people ask most.

Do I need to install anything or write code?

No. Everything runs in the browser. Code is there when you want it: every panel’s </> Code button shows the matching Python.

Is my data uploaded anywhere?

No. Your file is read on your own computer and never sent to a server.

Why do my numbers differ slightly from Python?

The models match scikit-learn and statsmodels, but random splits use a different random-number generator, so the exact rows in each split can differ. With the same split the numbers agree.

Where do I learn the theory?

Every panel has a Learn link to the lesson behind it, and the Learn section has the full path from the maths up to transformers.

The page looks out of date after an update.

Hard-refresh: Ctrl + Shift + R on Windows and Linux, Cmd + Shift + R on a Mac.
