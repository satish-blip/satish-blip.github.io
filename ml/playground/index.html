How to build a model here

Work left to right through the six tabs. Nothing leaves your browser, and every tool has a </> Code button with the matching scikit-learn code.

  1. Import data. Pick a sample or load a CSV, then choose the target (the column to predict). Mark ID columns and anything that gives the answer away as ignore.
  2. Check the data. Fix what the health checks flag (missing values, duplicates, skew, outliers). Use Transforms and Feature scales to see whether columns need a log transform or scaling, Correlation + VIF for features that repeat each other, and t-SNE / PCA for whether the classes separate at all.
  3. Build the pipeline. Keep a test set aside (20% is typical) and turn on cross-validation. Add only the steps the checks asked for: imputation, transforms, encoding, scaling (needed for KNN, SVM, PCA and penalised linear models; not for trees), feature selection, class balancing. Then pick a model and press Train & evaluate.
  4. Read the output. Compare train and test scores: a big gap means over-fitting (simplify the model, add regularisation). The Pipeline graph shows what each stage did; Diagnostics and Statistics explain the errors and coefficients; Compare models ranks every model on the same pipeline.
  5. Test it. Type in a new row and watch the prediction change, browse the test-set mistakes, or score a whole CSV.
  6. Take it with you. Export the Python script or notebook, save the settings, or run the exported code in real Python on this page.

Rules of thumb

  • Start simple. Logistic or linear regression is the baseline; only keep a complex model if it beats the baseline on cross-validation.
  • Never tune on the test set. Use cross-validation and grid search for choices; look at the test score once, at the end.
  • Leakage beats everything. A near-perfect score usually means a column gives the answer away. Every step here is fitted on training rows only.
  • Imbalanced classes: judge with balanced accuracy, F1 or ROC AUC, not accuracy, and try class weights.
  • Minimise what you don't need. The ⌃ button on each panel folds it away; tiles slide sideways.
