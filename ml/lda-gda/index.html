LDA & GDA

Logistic regression asks "where is the boundary?" directly. Gaussian discriminant analysis takes the opposite route: it first learns what each class looks like, as a bell-shaped cloud, and only then asks which cloud a new point most likely came from. Share one cloud shape across classes and the boundary is a straight line (LDA); give each class its own shape and it bends (QDA). Drag the class means, change the priors, and see Fisher's projection that LDA secretly finds.

What are LDA and GDA, in plain words?

The problem

A fish factory sorts its catch into salmon and sea bass using two measurements: length and brightness. We have a few hundred labelled fish. When a new fish comes down the belt, which is it?

Two ways to answer

A discriminative method (logistic regression, an SVM) looks only for the line that best separates the labelled fish. A generative method first builds a description of each species: "a typical salmon is about this long and this bright, and they vary like this". It then asks which description makes the new fish more plausible. That is GDA.

The idea

Describe each class as a bell-shaped cloud with a centre (mean) and a shape (covariance matrix, which says how spread out the cloud is in each direction and how tilted). A new point is given to the class whose cloud makes it most likely, adjusted by how common each class is (the prior), using Bayes’ rule.

LDA assumes every class cloud has the same shape, which gives a straight boundary. QDA lets each class have its own shape, giving curved boundaries. Naive Bayes assumes the features are independent within a class, so the clouds are never tilted.

How it works

  1. Estimate each class’s mean and covariance from the training data.
  2. Estimate how common each class is (the prior).
  3. For a new point, compute a score per class: how likely the point is under that class’s Gaussian, times the prior.
  4. Pick the class with the highest score.

An everyday picture

A doctor who has seen thousands of patients has a mental picture of what "typical flu" and "typical cold" look like across temperature and fatigue. Faced with a new patient, they don't draw a line; they ask which picture fits better, and they also know flu is rarer in summer. That last part is the prior.

Good at
  • Very fast, no iterations: fitting is just averaging
  • Works well with little data when the Gaussian assumption is roughly right
  • Gives probabilities and a projection (Fisher LDA) for visualisation
  • Can generate new, realistic-looking data
Watch out for
  • Wrong shape assumptions hurt (moons, spirals)
  • QDA needs many points per class to estimate covariances
  • Sensitive to outliers, which drag means and covariances

2The maths

Three steps again: write down the story of how the data was generated, estimate its pieces from the data, then turn it around with Bayes' rule to classify.

Step 1: a story for how the data appears

Imagine nature producing a fish: first it flips a biased coin to choose the species (\(y=1\) with probability \(\pi_1\)), then it draws the measurements from that species' Gaussian. To classify, we run the story backwards with Bayes' rule: given the measurements, how likely is each species?

$$y\sim\mathrm{Bernoulli}(\pi_1),\qquad x\mid y=k\ \sim\ \mathcal N(\mu_k,\Sigma_k),\qquad P(y=k\mid x)=\frac{\pi_k\,\mathcal N(x;\mu_k,\Sigma_k)}{\sum_j\pi_j\,\mathcal N(x;\mu_j,\Sigma_j)}$$

The denominator is the same for every class, so to pick the winner we only compare the numerators. Taking logs (which keeps the order) gives each class a discriminant \(\delta_k(x)=\log\pi_k+\log\mathcal N(x;\mu_k,\Sigma_k)\):

$$\delta_k(x)=-\tfrac12\log|\Sigma_k|-\tfrac12(x-\mu_k)^\top\Sigma_k^{-1}(x-\mu_k)+\log\pi_k$$

Read the three terms: the middle one is (minus half) the squared Mahalanobis distance from \(x\) to the class centre, a distance that accounts for the cloud's shape, so being far along a cloud's long axis costs less than being far along its short axis. The first penalises big, spread-out clouds (they spread their probability thinly). The last favours common classes.

Step 2: estimate the pieces (closed form)

Maximising the joint likelihood \(\prod_i P(x_i,y_i)\) gives the answers you would guess: the fraction of each class, the class average, and the class spread.

$$\hat\pi_k=\frac{n_k}{n},\qquad \hat\mu_k=\frac1{n_k}\sum_{y_i=k}x_i,\qquad \hat\Sigma_k=\frac1{n_k}\sum_{y_i=k}(x_i-\hat\mu_k)(x_i-\hat\mu_k)^\top$$

No iterations, no learning rate: fitting is just counting, averaging and computing covariances. LDA pools the two: \(\hat\Sigma=\tfrac{n_0}{n}\hat\Sigma_0+\tfrac{n_1}{n}\hat\Sigma_1\).

Algorithm: fitting and predicting with GDA
  1. input training points \(x_i\in\mathbb R^d\) with labels \(y_i\in\{0,\dots,K-1\}\), model ∈ {LDA, QDA, NB}, shrinkage \(\alpha\)
  2. for each class \(k\) do
  3. \(\pi_k\leftarrow n_k/n\); \(\mu_k\leftarrow\) mean of the class's points
  4. \(\Sigma_k\leftarrow\) covariance of the class's points
  5. if LDA then \(\Sigma_k\leftarrow\sum_j\pi_j\Sigma_j\) for all \(k\) one shared shape
  6. if NB then zero every off-diagonal entry of \(\Sigma_k\) no tilt
  7. \(\Sigma_k\leftarrow(1-\alpha)\Sigma_k+\alpha\frac{\operatorname{tr}\Sigma_k}{d}I\) shrinkage
  8. to predict \(x\):
  9. for each \(k\): \(\delta_k\leftarrow\log\pi_k-\tfrac12\log|\Sigma_k|-\tfrac12(x-\mu_k)^\top\Sigma_k^{-1}(x-\mu_k)\)
  10. \(P(y=k\mid x)\leftarrow e^{\delta_k}/\sum_je^{\delta_j}\) softmax of the discriminants
  11. return \(\arg\max_k\delta_k\) and the probabilities
Going deeper: deriving the maximum-likelihood estimates

The joint log-likelihood splits into a part for the priors and a part for each class: \(\ell=\sum_i\log\pi_{y_i}+\sum_k\sum_{y_i=k}\log\mathcal N(x_i;\mu_k,\Sigma_k)\). The prior part is maximised subject to \(\sum_k\pi_k=1\) with a Lagrange multiplier: \(\partial/\partial\pi_k\big(n_k\log\pi_k-\lambda\pi_k\big)=0\Rightarrow\pi_k=n_k/\lambda\), and the constraint gives \(\lambda=n\).

For one class, \(\log\mathcal N=-\tfrac d2\log2\pi-\tfrac12\log|\Sigma|-\tfrac12(x-\mu)^\top\Sigma^{-1}(x-\mu)\). Setting the gradient in \(\mu\) to zero gives \(\Sigma^{-1}\sum(x_i-\mu)=0\), so \(\mu\) is the average. For \(\Sigma\), work with the precision \(\Lambda=\Sigma^{-1}\) and use \(\nabla_\Lambda\log|\Lambda|=\Lambda^{-1}\) and \(\nabla_\Lambda\,v^\top\Lambda v=vv^\top\): the condition \(\tfrac{n_k}{2}\Lambda^{-1}-\tfrac12\sum(x_i-\mu)(x_i-\mu)^\top=0\) gives the sample covariance with divisor \(n_k\). (The unbiased estimator divides by \(n_k-1\); it is not the MLE.)

Because the joint likelihood factorises, everything has a closed form. Logistic regression maximises only the conditional likelihood \(\prod P(y_i\mid x_i)\), which does not factorise, hence it needs iteration.

Step 3: LDA, where the quadratic terms cancel

With a shared \(\Sigma\), the \(x^\top\Sigma^{-1}x\) and \(\log|\Sigma|\) terms are identical in \(\delta_0\) and \(\delta_1\). Subtract the two discriminants and they vanish, leaving log-odds that are linear in \(x\):

$$\begin{aligned}\log\frac{P(y=1\mid x)}{P(y=0\mid x)}&=w^\top x+c,\qquad w=\Sigma^{-1}(\mu_1-\mu_0),\\ c&=-\tfrac12\mu_1^\top\Sigma^{-1}\mu_1+\tfrac12\mu_0^\top\Sigma^{-1}\mu_0+\log\tfrac{\pi_1}{\pi_0}\end{aligned}$$

That is exactly the form of logistic regression: \(P(y=1\mid x)=\sigma(w^\top x+c)\). The difference is how \(w\) is found: LDA from the Gaussian estimates, logistic regression by maximising the conditional likelihood directly. Interpret \(w\): it points from one mean to the other, then gets "unstretched" by \(\Sigma^{-1}\) so that directions in which the clouds are wide count for less.

QDA and naive Bayes

QDA keeps \(\Sigma_0\neq\Sigma_1\), so the quadratic terms no longer cancel and the boundary \(\delta_1=\delta_0\) is a conic: ellipse, parabola or hyperbola. It needs more parameters (\(2\times3\) covariance entries here instead of 3; with \(d\) features, about \(Kd^2/2\)), so it can overfit with few points. Gaussian naive Bayes forces each \(\Sigma_k\) to be diagonal (features independent given the class), which gives axis-aligned ellipses and only \(Kd\) variances to estimate.

Try Unequal covariance: LDA must use one straight line, QDA wraps a curve around the tight class. Then try Circles: QDA's ellipse works, LDA fails. On XOR and Spirals neither Gaussian story fits.
Going deeper: generative vs discriminative, who wins when?

Every GDA model implies a logistic posterior, but not every logistic posterior comes from Gaussians (Poisson or exponential class-conditionals also give one). So GDA makes a stronger assumption. When that assumption holds, GDA is asymptotically efficient: no consistent estimator does better with lots of data, and with little data it needs fewer examples to reach good accuracy (Ng and Jordan, 2002, showed logistic regression needs \(O(d)\) examples where naive Bayes needs \(O(\log d)\) to approach its own limit). When the assumption is wrong, GDA converges to the wrong boundary however much data you have, while logistic regression keeps improving. Rule of thumb: little data and roughly Gaussian features, use LDA; lots of data or clearly non-Gaussian features, use logistic regression.

Regularised discriminant analysis. With few points or many features the sample covariance is noisy and can be nearly singular, so \(\Sigma^{-1}\) explodes. The shrinkage slider replaces it by \(\hat\Sigma_\alpha=(1-\alpha)\hat\Sigma+\alpha\,\tfrac{\operatorname{tr}\hat\Sigma}{d}I\) (Ledoit and Wolf; scikit-learn's LinearDiscriminantAnalysis(solver="lsqr", shrinkage=α)). This is the covariance version of an L2 / ridge penalty: at \(\alpha=1\) LDA ignores correlations and becomes a nearest-mean classifier (after scaling). Try QDA with 20 points and raise \(\alpha\). See the L1 and L2 regularisation page.

3Fisher's view: the best 1-D projection

Fisher arrived at the same answer from a completely different question, with no Gaussians at all: if we must squash the data onto a single line, which direction \(u\) makes the two classes as separated as possible relative to their spread? Rotate \(u\) and watch the histograms and the criterion \(J(u)\).

$$J(u)=\frac{\big(u^\top(\mu_1-\mu_0)\big)^2}{u^\top S_W\,u}$$$$u^\star\propto S_W^{-1}(\mu_1-\mu_0)$$

The top is the squared distance between the projected means (we want it large); the bottom is the projected within-class spread \(S_W\) (we want it small). The optimum is the LDA direction \(w\) from section 2: two different derivations, one answer.

Projecting onto \(\mu_1-\mu_0\) (the line joining the means) ignores the shape of the clouds. On elongated, tilted classes (try Linear blobs with noise, or Overlapping) the Fisher direction is noticeably better because it also divides by the spread.

Going deeper: maximising the Fisher criterion

\(J\) does not change if \(u\) is scaled, so fix the denominator, \(u^\top S_Wu=1\), and maximise the numerator \(u^\top S_Bu\) with \(S_B=(\mu_1-\mu_0)(\mu_1-\mu_0)^\top\). The Lagrangian \(u^\top S_Bu-\lambda(u^\top S_Wu-1)\) gives \(S_Bu=\lambda S_Wu\), a generalised eigenvalue problem. Here \(S_Bu=(\mu_1-\mu_0)\,[(\mu_1-\mu_0)^\top u]\) always points along \(\mu_1-\mu_0\), so \(S_Wu\propto\mu_1-\mu_0\) and \(u\propto S_W^{-1}(\mu_1-\mu_0)\). With \(K\) classes, \(S_B\) has rank \(K-1\), so LDA can give at most \(K-1\) useful projection directions: the top generalised eigenvectors. That is LDA as supervised dimensionality reduction, the labelled cousin of PCA.

4It's generative: sample new data from the model

A discriminative model (logistic regression, SVM) only learns \(P(y\mid x)\). A generative model learns \(P(x,y)=P(y)P(x\mid y)\), so it can invent new data by running its story forwards. Press the button to draw fresh points from the fitted Gaussians (hollow) next to the real data (filled).

This is also a quick health check. If the fake points look like the real ones, the Gaussian assumption is reasonable and GDA will do well. If they look nothing alike (moons, spirals), the model is mis-specified, and a discriminative method will usually win.

$$x_{\text{new}}=\hat\mu_k+L_k z,\quad z\sim\mathcal N(0,I),\quad L_kL_k^\top=\hat\Sigma_k\ (\text{Cholesky})$$
Algorithm: sampling from the fitted model
  1. for \(s=1\) to \(m\) do
  2. draw class \(k\) with probability \(\pi_k\) flip the biased coin
  3. draw \(z\) with \(d\) independent standard normal entries
  4. \(x\leftarrow\mu_k+L_kz\) \(L_k\) stretches and tilts the round cloud into the class shape
  5. emit \((x,k)\)

Why does this work? \(z\) has covariance \(I\), and a linear map \(L\) turns covariance \(C\) into \(LCL^\top\), so \(Lz\) has covariance \(LL^\top=\hat\Sigma_k\). See Cholesky.

5The same thing in Python

from sklearn.discriminant_analysis import LinearDiscriminantAnalysis, QuadraticDiscriminantAnalysis
from sklearn.naive_bayes import GaussianNB

lda = LinearDiscriminantAnalysis(store_covariance=True).fit(X, y)
lda.means_, lda.covariance_, lda.priors_, lda.coef_, lda.intercept_   # mu_k, Sigma, pi_k, w, c
qda = QuadraticDiscriminantAnalysis(store_covariance=True).fit(X, y)   # qda.covariance_ is a list, one per class
nb  = GaussianNB().fit(X, y)

# by hand, two classes
mu0, mu1 = X[y == 0].mean(0), X[y == 1].mean(0)
Sw = np.cov(X[y == 0].T, bias=True) * (y == 0).mean() + np.cov(X[y == 1].T, bias=True) * (y == 1).mean()
w = np.linalg.solve(Sw, mu1 - mu0)        # Fisher / LDA direction
LinearDiscriminantAnalysis(n_components=1).fit_transform(X, y)  # LDA as supervised dimensionality reduction
